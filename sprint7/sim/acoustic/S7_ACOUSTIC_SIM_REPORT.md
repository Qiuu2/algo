### 0.2 指标口径（全项目统一）
- **BW = −6 dB 全角**（2×单边半角，0.01° 网格线性插值）。一秒判据：每格断言 BW(−6) > BW(−3) 且峰在 0°（全部通过）。
- **SLL** = 峰值旁瓣（dB re 主瓣）。主瓣 = 峰向两侧走到第一个局部极小；旁瓣 = 其外最大值。若该瓣**触及 ±90°** 标 **E**（部分瓣，6 kHz 处即 d≈λ 的**栅瓣肩**，是几何效应不是窗设计旁瓣）；另给 **SLLint** = 严格在 ±90° 内的最高旁瓣。主瓣填满可见区 → nan。
- **DI** = 10log10(|Σw|² / Σᵢⱼ wᵢwⱼ sinc(k|xᵢ−xⱼ|))（3-D、各向同性阵元、闭式；与数值积分互核 A7）。
- **WNGn** = 10log10(|Σw|²/(N·Σw²))，**相对均匀阵**（均匀 = 0 dB）；**WNGa** = 10log10(|Σw|²/Σw²)（m3 口径，均匀 = +12.04 dB）。二者差恒 12.04 dB。
- **att30 / att90** = −20log10|AF(θ)/AF(0)|（正 dB，JY/T 表 9 "SPL 差值"口径）。注意：当 30°/90° 恰落在零点附近时会出现 50–180 dB 的大值，**±1° 就会变，不具鲁棒性**，只应读作"≫门限"。

## 1. 本仿真能回答 / 不能回答什么

**能回答**（阵因子层、相对量、broadside、对称加权）：
1. 在同一 825 mm 孔径、同一 16 点源阵因子上，各窗的 BW/SLL/DI/WNG/30° 衰减随频率的**相对**关系与代价。
2. 用实现的 1.5k/3k/6k 子带、每子带一套标量权重，−6 dB 波束宽跨 1–6 kHz 的**可达平坦度下限**及其代价。
3. 低频（250–1k）算法层（超指向 MVDR）在 8 对对称约束下能把 BW 压到哪里、要付多少 WNG。
4. 一旦每通道有分数延时，"置换权重下标"与"置换 TX 槽位"的**数值差异**（焦点损失 dB、方向图偏差）。

**不能回答**：
1. 任何**绝对** SPL、绝对波束宽验收值（阵元指向性/障板衍射未建模；≥2 kHz 宽角偏乐观 PF-6）。
2. 180°/后向抑制（模型前后对称，R9）。
3. 6.2 kHz 以上栅瓣区（本报告最高只算到 6 kHz，且 6 kHz 行已带栅瓣肩）。
4. 子带交叠区的真实纹波：实现的差分金字塔 detail 子带**跨倍频程有泄漏**、"各子带增益差异大时交叠区出现纹波"（`tree_filterbank.h:11-15`），本报告按理想砖墙子带算，**每子带不同窗的真实交叠行为须 DSP 侧仿真/上板**。
5. 混响/房间/近场装置效应；元件幅相散差下的鲁棒性（WNG 只给理论指标，须 M2 蒙特卡洛 + 实测）。

## 3. B5-2 "每子带不同旁瓣电平 / 恒定波束宽"评估 [L2/numpy]

### 3.1 物理下限与目标的定法（先讲理由）
1. **1 kHz 是硬地板**：825 mm 孔径上 −20 dB 旁瓣族的最窄 −6 dB 全角 = Dolph-20 的 **29.27°**（均匀阵 27.20° 但 SLL −13 dB；再窄只能超指向，见 §5）。恒定波束宽只能把高频**拉宽**到这个量级，**1 kHz 不会因此变窄一度**。
2. **标量权重的倍频程纹波是 2:1**：每子带只有一套 8 个标量权重，对固定权重 BW ∝ λ（小角近似，30° 内误差 ~1%），因此 1.5–3k、3–6k 两个倍频程子带内 BW 各自必然从带下沿到上沿**减半**。1–1.5k 子带段是 1.5:1。
3. 所以全局 (max−min) 的解析下限 ≈ BW(1k)/2 = **14.63°**（各子带把带下沿波束宽都拉到 29.27°，带上沿必到 14.6°）。要低于这个下限只有两条路：**更细子带**（改 DSP 树）或**每通道短 FIR 频变加权**（A2 §1.2 第②层，有算力/延迟代价）。
4. 因此本评估的目标 = **在 1–6 kHz 上最小化 max−min，SB0 固定为冻结 Dolph-20**（不动 1 kHz 规格锚），SB1/SB2 各搜一套标量窗（候选族：Dolph SLL 20–120、Kaiser β 0–30、Gaussian σ 0.8–12 元、Taylor nbar=4 SLL 20–50、§2 目录窗；共 175 个候选、30 625 个组合穷举）。采样点：1k–1.5k 5 点、1.5–3k 7 点、3–6k 7 点（对数等距，含边沿）。

即：把 3–6k 子带拉宽到 29°→14° 之后，**5.5 kHz 起 ±90° 只剩 6 dB 以下、6 kHz 几乎 0 dB 衰减**（现状 Dolph-20 在 6 kHz 也只有 5.2 dB，本就是降级规格上限 6k(对内)/5k(对外) 的由来）。恒定波束宽设计在 d=55 上**只在 ≤5 kHz 有意义**，与现行对外 5 kHz 上限一致；不能宣称 6 kHz。

### 3.5 一句话物理结论（B5-2）
- 用实现的 1.5k/3k/6k 子带 + 每子带一套标量权重，−6 dB 波束宽在 1–6 kHz 的跨频平坦度可从 **24.4°（固定 Dolph-20）压到 ≈15.0°（下限 14.6°）**[L2]；再往下须细分子带或每通道短 FIR。
- 这买的是**覆盖均匀性**（高频从 4.8° 拉宽到 14.3°，1.5–3k 从 19–10° 拉宽到 29–14°），**不是低频变窄**：BW(1k) 在所有设计里恒为 29.27°。与 `EXP_COMPET_BEAM_VS_FREQ.md §0` 的表述一致。
- 代价 [L2]：DI@4k −4.35 dB、WNGn −4.62 dB、3–6k 满驱动轴向 SPL −9.9 dB（Σw 4.14/16 [L3]）、5.5–6 kHz ±90° 泄漏接近 0 dB；DI@2k −1.54 dB、1.5–3k 轴向 SPL −3.85 dB。收益的副产品：2 kHz/90° 由 23.01（二级）→ 57 dB（一级）、SLL 全部 ≤ −38 dB。
- 若只允许每子带 WNGn ≥ −3 dB，平坦度只能到 19.4°（改善 5°），此时 SB2 用 dolph120（有效长度 0.43 m，Σw 5.9/16，轴向 −6.8 dB）。
