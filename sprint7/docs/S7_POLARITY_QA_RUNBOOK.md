### 0.4 判据纪律：什么叫"明显"（全手册通用的操作定义）

本手册所有"明显高于 / 明显低于 / 大致齐"都按下面的**相对**规则判，不用任何绝对 dB 数：

1. **每个读数取 3 次**（麦不动、设置不动、每次重新读稳后抄原值），记三个原值和**中值**；三个原值的 **max−min = 该读数的"散布"**；散布取 `max(三值极差, 仪器显示分辨率 1 步)`（三次同值时散布不为 0；分辨率是仪器属性，记入 R10 第 1 项，不是声学期望）。
2. 两个读数 A、B 的**中值之差**，若**大于两者散布中较大的那个** → 算"明显"（A 明显高于 B 或反之）。
3. 中值之差**不大于**较大散布 → 算"**分不清**"，不判，走 §3 的失败处理（挪麦 / 换参考路 / 复测）。
4. "**大致齐**"= 两两之间都分不清（按第 3 条）。
5. 读数与**本底**的比较同样用第 2 条（本底也取 3 次）。
6. 任何一步的三次原值散布异常大（同一点读数来回跳）→ 先查风、脚步、手机 App 档位，再重测；仍跳 → 记"读数不稳"发回，不硬判。

> 为什么不给阈值：手机分贝计半定量、近场散斑、375 Hz 小喇叭效率未知，任何事先写死的 dB 门在本 rig 上都可能造成假绿或假 FAIL（`S7_VERIFICATION_PLAN.md §0.1 ③` / `.claude/skills/testing/SKILL.md A4`）。

## 1. Step A —— 电池纸盆法逐只（定论法，[L1 逐只，机械位移法]）

> 原理（[L3] 背景）：给喇叭两端加一个直流瞬间电压，纸盆会朝一个方向位移；同一电池极性下所有"外弹"的那一端就是同一极性端。它测的是**机械位移**，与声压无关，所以不受 solo-SPL 对极性盲的限制，也不受声学分辨率限制（`EXP_STATIC_POL375.md §7`）。

### 1.1 断电与断线

1. **功放断电**（拔电源，不只是关音量）；板可不通电。
2. 把每只喇叭**从串联对和功放两侧都断开至少一端**，使被测那只**电气上孤立**（串联对里另一只若还连着，电池电流会同时过两只，纸盆动作互相干扰，判不准）。
3. 断线前先**拍照**原接法（每对一张，看清哪根线接哪个端子），照片编号写进记录表 A1 备注。

### 1.2 物理位置标签

4. 面对阵列正面（发声面朝你），**横放**时从左到右给 16 只贴 **pos0 … pos15**（pos0 / pos15 = 最外两只，pos7 / pos8 = 最中心两只）。方向约定一旦定下**整份记录不改**，并在 A1 表头写明"pos0 在左"或"pos0 在右"。
5. 同时在每只喇叭端子旁留空位贴 +/− 标签（§1.4 判完再贴）。

### 1.3 瞬触规则（1.5 V 首选，9 V 例外）

| 规则 | 内容 |
|---|---|
| 首选 | **一节 1.5 V 新电池**。两根导线一端各夹电池两极，另一端**同时瞬间轻碰**喇叭两个端子，**碰一下就松**（不超过约一秒），观察纸盆动作。 |
| 观察姿势 | 眼睛平视纸盆边缘，光从侧面打；也可用指腹**极轻**搭在纸盆边缘感受"往外顶 / 往里缩"（触感法只作辅助，最终以目视或两法一致为准）。 |
| 例外 | 小喇叭 1.5 V 位移看不清 → 换 **9 V 电池**，**只允许极短瞬触**（点一下即离），同一只**最多两次**，两次之间停几秒。**禁止按住不放**。 |
| 禁止 | 不得用任何高于 9 V 的电源；不得对仍连着功放或仍串联着另一只的喇叭做电池测试；不得在功放通电时做；不得反复连续瞬触同一只（发热）。 |

### 1.4 观察与约定（"外弹端标 +"）

6. 约定：**电池 + 极所碰到的那个喇叭端子，若碰触瞬间纸盆向外弹（朝你）→ 该端子标为喇叭 "+"**；另一端标 "−"。
7. 若碰触瞬间纸盆**向内缩** → 说明电池 + 碰到的是喇叭 "−"；把导线**对调**再碰一次确认外弹，再贴标签。
8. 哪一端叫 "+" 是**约定**，不是绝对真理；重要的是 **16 只全用同一约定**（`EXP_STATIC_POL375.md §7` 第 4 条）。

### 1.5 复测规则与"看不清 / 存疑"

9. **每只至少做两次**（可以是"正碰外弹 + 对调内缩"这一组），两次结论一致 → 记"确定"。
10. 两次不一致、或任一次看不清 → 记"存疑"，按 §1.3 换 9 V 复测一次；一致了记"确定(9V)"，仍不一致或仍看不清 → 记 "**未定**"，**不猜**，留到 §3 处理（该只所在通道进 Step B 时标"极性候选"）。
11. 存疑/未定的喇叭在 A1 表"备注"里写清现象（如"位移极小""两次方向不同"）。

## 2. Step B —— 375 Hz 成对声学复验（通道级，[L1 通道级]）

> 原理（[L3] 背景，**不作阈值**）：两路同放 375 Hz 等幅单音时，若极性相同，两路声波相干相加，正前的读数比任一单放**更响**；若极性相反，相减，读数比任一单放**更弱**（理想等幅等距时接近抵消）。选 375 Hz 是因为它的波长（约 915 mm [L3]）与阵长同量级，近场相消区宽、不像 2250 Hz 那样把外侧对误判成反相（`EXP_STATIC_TXTEST.md §4 ⑦`；`EXP_STATIC_POL375.md` 顶注）。
> **分辨率边界（必须记住）**：掩码只能控 8 路通道，控不到单只喇叭。本步**结论只到通道级**；通道内一只反接会表现为该路 solo 变弱（两只近距反相自抵消），**说不出是哪一只**——这正是 Step A 存在的理由（`EXP_STATIC_POL375.md §0`）。

### 2.1 build 宏组合与凭证

1. `git pull`（报 `local changes would be overwritten` → 原样发回，不 reset）。
2. Preprocessor → Defined symbols 里应有（**且只有**下列 M2 相关宏）：
   - M2 常规两个：`M2_FIRA_INLOOP=1`、`FIRA_USE_REAL_ADI_FIR_HEADER`（`BOARD_TEST_INSTRUCTIONS.md` 第 2 步）；
   - 本诊断两个：`M2_STATIC_TXTEST=1`、`M2_STXT_LOCALIZE=1`（`EXP_STATIC_POL375.md §1`）。
   - **不要加** `M2_CHMAP_FIX`、`M2_RX_RIGHT_ALIGNED`（本会话用不到；少一个变量少一个坑）。
3. **三宏缺一不可**：`M2_STATIC_TXTEST` 缺 `M2_FIRA_INLOOP=1` 时，M1 回调会每帧覆写"静态"缓冲，静态前提被静默破坏（PM 审计 `fw_code_audit.md §9.C`）。`#error` 守卫与两个运行时指纹 `g_m2_static_txtest_built` / `g_m2_stxt_localize_built` 已随 D3 包实现（同批入库）；**在它们入库之前，测试员须自行确认三个宏都在**：Defined symbols 截图 + Console 里 `m1_loopback_tdm.c` 编译行含三个 `-D`，两张截图都是交付物。
4. **Rebuild（必须显式做一次）**；只在 loader 步报 FAILED 而 `.dxe` 已生成 → 忽略继续（`BOARD_TEST_INSTRUCTIONS.md 〇-5`）。

### 2.2 上板与安全顺序

5. 板断电 → 插 JTAG → 板上电 → 仿真器上电（§0.3）。**功放断电**。
6. Load `Debug/M1_Loopback.dxe`。⚠ 静态模式下**掩码默认全开**（8 路同时出 375 Hz），所以第一次 Run 必须功放断电。
7. 按 `BOARD_TEST_INSTRUCTIONS.md` 接好立体声音源（只为让 `g_m1_fg_stream_live` 可判；静态 375 Hz 音**不来自**输入源）。
8. **Run 约 5 秒 → Suspend → 读 §2.3 全表**。
9. gate 与 §2.4 格式门都过后：Suspend 状态下把 `g_stxt_ch_mask` 改为 **0x00**（全静音）→ Resume → 功放上电、音量最小。之后每次改掩码 = **Suspend → Expressions 改值 → Resume**，等主循环重填（一两秒）再读分贝计。本静态 build 的输出缓冲是固定的，JTAG 改值就是 `EXP_STATIC_POL375.md §2` 的设计用法；`BOARD_TEST_INSTRUCTIONS.md` 红线里"Resume 后音频不可信"针对的是**活波束 build**，此处不适用。

### 2.8 Phase B —— 成对极性（通道级 SAME / OPPOSITE / WEAK）

**参考路选法**
21. cR = Phase A 实测**物理居中**的那一路（响的是 pos7/pos8），**不默认 c7**（竞品 rig 上实测中间是 c3，`EXP_STATIC_POL375.md §2` 注）。cR 必须是 Phase A 里"不弱"的路。若居中路本身弱 → 先走 §3 第 2 行，不得用弱路当参考。

**麦位规则**
22. 麦在**阵列中心轴正前**（自家阵列每路是关于中心对称的镜像对，中心轴对任何一对的两只都等距，天然是最干净的位置）。**同一对的三项读数（L_ref / L_K / L_both）麦不动**。
23. 对**远距对**（cK 是外侧路、与居中 cR 相距远）：中心轴上麦距阵面太近时，麦到外侧对与到中心对的路径差大，相长/相消对比会变钝、零点变尖且对麦位敏感（critic F4，`EXP_STATIC_POL375.md §5` 几何注意；[L3] 背景：路径差随麦后退而缩小）。处理：**沿中心轴向后退**（不要侧移）再重测该对三项；后退后 solo 若与本底分不清，则退到仍能明显高于本底的最远位置。每次挪麦，三项**全部**重测。

**每对的三个读数（各 3 次取中值）**
24. 掩码 = solo cR → **L_ref**；掩码 = solo cK → **L_K**；掩码 = cR + cK 两路 → **L_both**。三项之间不动麦、不动功放。
25. 对其余 7 路 K 逐一做；每对做完掩码回 0x00 休息。

**判定规则（全部相对，§0.4 定义的"明显"）**

| 判定 | 规则 | 备注 |
|---|---|---|
| **SAME** | L_both **明显高于 L_ref 且明显高于 L_K** | 两路同极性 |
| **OPPOSITE** | L_both **明显低于 L_ref 且明显低于 L_K**；把麦沿中心轴前后挪一小段还能找到更低的读数 | 两路反极性（通道级） |
| **WEAK/DEAD（cK）** | L_K 与本底**分不清**，且 L_both 与 L_ref **分不清**（加了 cK 没变化） | 与 OPPOSITE 的区别：OPPOSITE 时 L_K 本身有量 |
| **分不清** | 其余任何情形（L_both 落在 L_ref 与 L_K 之间、或差都在散布内） | 不硬判，走 §3 第 3 行 |

26. **一致性自检（做完 7 对必填）**：Phase A "大致齐、不弱"的路在 Phase B 不应出现 WEAK；出现 → 该路记"矛盾"，走 §3。
27. **备选：相邻链式法**（当某对相对 cR 分不清时）：改用**相邻路**做参考（如 cK 与 cK±1，两者的喇叭在阵列两侧都彼此相邻，几何最近、相消最清楚），按同样三项读数判 cK 相对 cK±1 是 SAME/OPPOSITE；再借已判清的 cK±1 相对 cR 的结果**推出** cK 相对 cR（两个 OPPOSITE 相乘 = SAME）。链式推出的结果在 B2 表"方法"列写"链式(经 c__)"，并**尽量另找一条链交叉核**（两条链结论一致才记"确定"，否则"分不清"）。

### 2.9 Step B 完成判定

- **PASS（通道级）**：7 路全 SAME、无 WEAK、无分不清、§2.7 无弱路、§2.8-26 无矛盾。
- **有 OPPOSITE**：Step A 之后仍出现 OPPOSITE = 该路两只在 Step A 的结论或 A2 接回**至少有一处错**（因为 Step A 已把 16 只统一）。**不得直接翻线**：先走 §3 第 4 行（回 Step A 复核该路两只 + A2 该行），确认后才在**功放断电**下改线，改线后**重测该对三项**，应由 OPPOSITE 转 SAME。翻线只能在喇叭端（§0.1 单端事实）。
- **有 WEAK/弱路/分不清**：按 §3 处理；处理不完不算 PASS。
- **可选（当天顺带，不入本手册结论）**：去掉 `M2_STXT_LOCALIZE`、保留 `M2_STATIC_TXTEST=1`，跑 `EXP_STATIC_TXTEST.md` 的 2250 Hz 静态 Dolph 表（格式门按该文 §4 ③(c) 表逐字节对），近场看正前 vs 侧向的**相对**变化。它只是"极性统一后不再是平的"的定性佐证，**不作方向图规格，也不作本手册 PASS 条件**；正式判据回 P0/P1。

## 7. 安全与红线

1. **改线前功放断电**（拔电源）。电池测试时喇叭与功放、与串联对另一只都断开。
2. **375 Hz 低频短促**：每路/每对测完掩码回 0x00；不久驻；刺耳/破音/发热即停。相消零点处纸盆仍满冲程，不加增益。
