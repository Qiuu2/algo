# S7 逐只喇叭复响应测量与配对执行手册（侧抑 20→30 dB 线的第一个决定性实验）

> **一句话**：先对**现装配**留一份远场基线（建议，CTO 定），再把 16 只（或更多）喇叭**逐只**装进同一个治具，在同一条件下测 **1–4 kHz 的灵敏度和相位**（复响应），每只 3 次、参考喇叭周期复测；用 `sprint7/tools/s7_driver_pairing.py` 算出**散布怎样随频率变**、谁是离群/疑似反接、**现装配 vs 随机装配 vs 配对装配**的侧抑模型预测、以及配对表和每路修整量。**恢复还是重配、买不买备用喇叭、选哪张权重表，都等这份数据。**
> **性质**：测试员执行手册，**零代码、零 build 改动**。测试员**照做、抄原值、不判对错**；异常原样发回。**从柱体上拆喇叭 = 硬件动作，受铁律九 / C10 管（§2），CTO 签清单前不许动手。**
> **判据纪律**：本文**不写任何喇叭/阵列的期望读数**；现场门都是**同一会话内的相对比较**，或标明 **[L4] 暂定**（CTO 可改）；**必须由 CTO 定的上限/阈值写成命名空栏**（如 `V_JIG_MAX = ____`），集中在 §12。
> **状态**：R3c + delta 修订稿（testing teammate，2026-09-26；critic R3c CONDITIONAL 的 7 MAJOR + 6 MINOR 已处理；delta PASS_WITH_MINOR 的 3 MINOR + 1 INFO 已处理）。待 delta critic + CTO 常识审（三道关）；未过门前不作权威。**（↑状态更新 2026-09-27，PM）**：critic R3c delta 判 PASS_WITH_MINOR，剩余 MINOR 已修，已入库（commit `db301ef`）；**CTO 常识审待**，开工前请 CTO 过目，并填好 `V_JIG_MAX`、签字 C10。

## 0. 为什么先做这个实验

### 0.1 背景（每条带 L 标）

| 事实 | 出处 | 等级 |
|---|---|---|
| 侧向（±90°）抑制受**喇叭间离散**限制：随机误差下侧向平均地板 ≈ 误差方差 / WNG | Van Trees, *Optimum Array Processing*, eq. 2.208 | [L3] |
| 每路功放驱动**中心对称串联对 {c, 15−c}**；每路 DSP 修整只能修一对的**平均**，对内两只之差**修不了** | `TEST1_WIRING_FINGERPRINT_FIELDLOG_20260629.md §1`（06-29 TEST1 rig 的接线核）；`.claude/skills/testing/SKILL.md A0` | **[L1，限 06-29 TEST1 rig]**；自家现装配以极性 QA Phase A 实测为准，非 {c,15−c} → 停（§2.3） |
| PM 侧 Monte Carlo：逐只测 + 最像的两只配一对 + 最像的对放最高权重位置 + 修整，可大幅提高 ≥30 dB 的良率；若散布随频率变，纯增益修整帮助小 | `sprint7/docs/S7_SIDE30_ANALYSIS.md`；`sprint7/sim/side30/s7_sorting_mc.py`（seed 2026，**单频段、误差不随频率变**）；critic `sprint7/critic/CRITIC_{G,H}_SIDE30_*` | **[L2 on L4 散布假设]** |
| **配对的收益是按批而定的，不是一般规律**。工具自检 T16（连续纯延时散布、Dolph-35 候选表、口径 7 带、12 个固定种子）：16 只池配对+修整相对随机+修整中位**平均为正**（各带 +2.6…+5.3 dB，T16a），但**单批可以输**（各带 8–25% 的种子，T16a）。16 只池的收益主要来自"最像的对 → 最高权重位置"的上位规则（带均总收益 3.68 dB 中上位规则占 2.38 dB，T16b）；24 只池主要来自"从 24 只里挑 16 只"（总 4.54 dB 中上位规则只占 0.68 dB，T16c）；**不是来自实数修整**——纯延时散布下实数修整本身略负（各带 −0.08…−0.36 dB，T16d；用相位部分抵消后的在轴对和算幅度修整所致），机制见 T4b | `s7_driver_pairing.py --selftest` T16a–d、T4b（种子固定、可复跑；本手册只引用这些） | **[L2 合成 on L4 散布]** |
| 所以**配对值不值得做，以工具对本批数据的逐批比较为准**（工具 [5] 的"百分位"行），不以任何一般结论为准 | — | 规则 |
| 我们**不知道**真实散布的构成（幅度 vs 相位、常数 vs 随频率变），也不知道现装配在随机分布里的位置 | — | 未测 |
| 冻结 Dolph-20 表在**无误差各向同性模型**下的 ±90° 带平均值**本身低于 30 dB**；这是模型参考值、**不是物理上界**（喇叭/障板自身指向性可能使实测更高，但不能据此预期达标） | `s7_driver_pairing.py`（"无误差参考"行）；`S7_SIDE30_ANALYSIS.md §2` | [L2 模型] |

**结论（方向性）**：30 dB 需要"换权重表"和"控制离散"两件事**同时**成立；后者值不值得做、怎么做，由**真实复响应散布**决定 → 这就是第一个决定性实验（`S7_SIDE30_ANALYSIS.md §6` 第 4 步；2026-09-27 重排后，第 3 步改为拆前的现装配远场基线；30 dB 口径 = DEC-S7-SIDE30-01 ①）。

### 0.2 这个实验的输出喂给哪些决定（全部 CTO 裁定）

| 输出 | 喂给的决定 |
|---|---|
| **现装配（T0）预测 + 它在随机分布里的百分位**（工具 [4b][5]，`--as-built`） | C10-8：**原样恢复 vs 按配对表重装**；与现装配远场基线（[L1]）对照，检验模型 |
| 散布 vs 频率表 + "常数增益能解释的方差比例"（工具 [3]） | 实数修整（现架构）有多大用；是否把路线 B 提前 |
| 随机 vs 配对（两种上位规则）+ 百分位行（工具 [5]） | 是否重配；是否买备用喇叭、买多少（采购 = 须 CTO 签，§10.2） |
| 离群 / 疑似极性清单（工具 [2]） | OUTLIER → 换不换；POLARITY? → **先查接线/极性，别当坏品换** |
| 在候选权重表下重跑（`--chebwin` / `--weights`） | 远场 A/B 用哪两张表（`S7_SIDE30_FARFIELD_TEST.md §10`，板上切表 `M2_WTBL_SEL`） |
| 路线 B 理想化行 + 逐只复响应 CSV 本身 | 路线 B（每通道滤波器，DEC-S7-SIDE30-01 ③）：配对对它还值多少（只剩对内差）；CSV 是其"按实测喇叭数据做稳健设计"的输入（`S7_SIDE30_PERCH_FIR_DESIGN.md`） |

### 0.3 这个实验**不能**回答的
- 柱体的实际侧抑（要远场自由场测，`S7_SIDE30_FARFIELD_TEST.md`）。
- **每只喇叭的离轴（掠射）离散**：±90° 方向上每只喇叭是在接近 90° 离轴的方向辐射，各只的离轴响应之差**在轴测量看不到，在轴修整也修不了**（critic R2 MINOR-7）。本实验只测在轴；治具是否加测离轴样本见 §12 Q7。
- 箱体绕射、喇叭在柱内的互耦、功放 8 路通道增益差、串联对内阻抗分压的影响（模型都不含）；任何对外规格。

## 1. 器材（最低配置 + 退路）

| 方案 | 器材 | 能测 | 说明 |
|---|---|---|---|
| **A（首选）** | 2 通道 USB 声卡（≥1 路输出 + 2 路输入）+ XLR 测量麦（带校准文件）+ 幻象电源 + REW；声卡输出 R → 输入 R 直连作 **loopback 时间参考** | 幅度 + **可信相位/延时** | 每次测量的时间零点由 loopback 定，喇叭间延时差是真的 |
| **B** | USB 测量麦（带校准文件）+ 电脑声卡输出 + REW，开 REW **acoustic timing reference**（另一输出路接一只**全程固定不动**的参考小音箱） | 幅度 + 相位/延时（可信度取决于参考音箱是否真的没动） | 会话开始/中途/结束各做一次时间一致性核（§4.1） |
| **C（退路）** | USB 测量麦 + REW，**无时间参考** | **只有幅度可信** | 头块写 `timing_reference: none`；CSV 相位列**整列留空**（或保留但分析加 `--remove-delay`，延时散布随之不可见） |
| 不接受 | 手机分贝计 | — | 没有频响、分辨不了 0.1 dB 级差异 |

**所有方案都要**：小功放一台（或项目功放的一路，按 §2 规矩）；**真有效值万用表**（AC 电压测激励、Ω 档记 Re）；温度计；卷尺/卡尺；治具（§3）；每只喇叭的物理标签；Windows 笔记本（REW）。

**退路 C 做不到什么（写进结论）**：
1. **看不到相位/延时散布**——实数增益修整修不了的那一半；退路下工具预测在期望意义上**偏乐观**（不是上界也不是下界）。
2. **看不到极性**：反接一只在幅度上完全正常（工具自检 T9 专门证明这个盲区）→ 逐只极性**必须**用电池法（§2.2）。
3. 回答不了"散布是否随频率变"中相位那一半 → **不能**单凭退路数据决定买备用喇叭或定权重表；只作初筛。

器材采购（测量麦/声卡）是小额采购，仍须 CTO 批（§12 Q1）。

## 3. 治具设计（所有喇叭**完全同一**条件）

| 项 | 要求 | 为什么 |
|---|---|---|
| 治具 | **一个**小密闭箱或平障板，开孔匹配喇叭法兰，同一块密封垫；整个会话只用这一个治具（记 `jig_id`） | 箱/障板的响应对所有喇叭相同，在"相对批参考"里抵消 |
| 安装 | 同一组螺丝、同样拧到"贴死即停"（或同一把扭力起子同一档）；法兰与障板面贴平 | 装深差 1 mm 在 4 kHz 就是约 4° 相位（[L3]：360°×1 mm/85.75 mm）——安装重复性决定相位数据能不能用 |
| 朝向与极性 | 每只"+ 端子朝上"（或其它固定朝向，写进头块）；**电池法在装治具之前做**（§2.2），标 + 的端子接治具红线 | 保证"同一约定"；工具对相位截距 >90° 的只标 POLARITY?（查接线，不当坏品） |
| 麦位 | 麦用**刚性支杆固定在治具上**（不是另一个三脚架），正对振膜中心、同轴；距离固定并卷尺实测记入 `mic_distance_m`（选"喇叭直径的数倍"量级，定了就全程不动） | 麦位不动 → 距离/角度误差不进散布 |
| 反射 | 治具离地、离墙、离桌面尽量远；REW 冲激响应加窗，窗口在首个反射到达前结束；**所有测量同一窗口设置**（写进头块 `sweep`）。窗口长度 T 决定可信的最低频率约 1/T（[L3]：例如 5 ms ↔ 200 Hz，对应首反射额外路径约 1.7 m） | 会话中**屋里不许走动、不许挪东西**（反射几何变了就不再抵消） |
| 电平 | 恒压：同一功放、同一档位（胶带标记）、同一 REW 输出电平；会话开始用 1 kHz 正弦 + 万用表在喇叭端子测一次 Vrms，≤ `V_JIG_MAX` | 恒压驱动下比较灵敏度 |
| 线性门 | 参考喇叭在正常电平与降 6 dB 各测一次；REW 里把降 6 dB 那条 +6 dB 后与正常那条叠图，**1–4 kHz 内处处幅度差 ≤ `G_LIN` = 0.3 dB、相位差 ≤ 3°（[L4] 暂定，CTO 可改：____）** | 超了 = 在非线性区或噪声太大 → 降电平或查本底后重来 |
| 温度 | 记开始/结束室温；会话尽量短；空调/暖气风口不对着治具 | 喇叭参数与声速随温度变；参考喇叭复测会暴露漂移 |
| Re | 每只拆下后用万用表 Ω 档记直流电阻（表笔短接读数先扣掉） | 串联对内阻抗分压的后续建模用（工具当前不用，先记） |
| 离轴样本（可选，§12 Q7） | 若 CTO 要求：同一治具上再测每只在一个固定离轴角的响应（角度 `θ_OFF = ____°`，CTO 定），同样 3 rep，另存一个 CSV（头块 `mic_position` 写明角度） | ±90° 方向上各只是近掠射辐射，离轴离散在轴测不到（§0.3） |

## 4. 采集协议

### 4.0 （可选，拆之前）就地近场初看（§12 Q6）
不拆、不动线：现装配、板跑 M2（build/gate 同 `S7_VERIFICATION_PLAN.md §8.1` 步 1–2，功放安全 §0.5），扫频从板输入进，麦**贴近**每只喇叭振膜中心（固定小距离 `d_CLOSE = ____ mm`，全程同一值）逐只测，时间参考同 §1 方案 A/B。
- **能看**：**对内差**——同一对的两只共用一路权重和一路功放，二者就地响应之比直接就是对内两只之差（正是修整修不了的那一半）。
- **看不清**：对与对之间的比较（混着通道权重与功放通道增益）；相邻喇叭串音（中心对两只相距仅 55 mm）；振膜近场与箱体影响。
- **定级**：[L1 就地近场，受串音污染，只作相对初看]；工具的配对/预测**不适用**于就地数据，PM 手工取对内差。用途 = 决定拆不拆（C10 之前）。

### 4.1 开工核查（每个会话，按顺序）
1. 器材预热 10 分钟；REW 选对输入/输出、载入麦校准文件；方案 A 确认 loopback 生效，方案 B 确认参考音箱摆好且之后**不再碰**。
2. 测本底：扫频关闭（功放通电、接着治具），麦位读一次，记 `background`。
3. 装上参考喇叭 R，**连测两次不动它**。**时间门**：REW 叠图，1–4 kHz 内处处幅度差 ≤ 0.2 dB、相位差 ≤ 3°（**`G_TIME`，[L4] 暂定，CTO 可改：____**）。超了 = 时间参考不工作（整样本跳变在 4 kHz 就是约 30°）→ 停，按退路 C 处理并在头块写明。
4. 线性门（§3）。
5. R 再按 §4.3 的"拆了再装"做满 3 次（R 的 rep1–3）——这就是本会话第一份真实重复性，**之后的门由 PM 用工具按它复核**（§4.6）。

### 4.2 扫频设置（整个会话不改，全部写进头块 `sweep`）
- 对数扫频，覆盖**至少 200 Hz–10 kHz**（工具分析区间 891–4490 Hz = 1k…4k 七个 1/3 倍频程带的带边并集，两头留余量）；采样率 48 kHz；长度 ≥256k；每次测量内部平均次数固定。
- 导出：REW "Export measurement as text"，**所有测量同一导出设置**（同一频率点数/PPO、不平滑），频率网格必须完全相同（工具会查，不同就拒收）。

### 4.3 测量顺序
1. **参考喇叭 R**（从批里挑一只，ID 写进头块 `ref_driver_id`）先测（§4.1）。
2. 其它喇叭按 ID 顺序，每只测 **3 次**（每次换装都走 C10-7 的五步）：
   - rep1：装上 → 测；
   - rep2：**拆下再装上** → 测；
   - rep3：**再拆下再装上** → 测。
3. **每测完 N 只复测一次 R**（`N = 4`，[L4] 暂定，CTO 可改：____），rep 编号接着往下排（R 的 rep 一直递增）。
4. 最后再测一次 R 收尾。
5. 有备用喇叭一并测（池子越大，配对越有余地）；离群判定是全批一起算的。

### 4.4 每条测量要记（记录本上，与 CSV 对应）
driver_id、rep、时间、（每次测 R 时）室温、备注（擦圈/异响/安装异常/有人进出房间等）。

### 4.5 文件
- REW 每条导出存为 `<driver_id>_r<rep>.txt`（例：`D07_r2.txt`），放同一目录。
- 头块写成 `header.txt`（每行 `key: value`，键见 §5.1）；现装配表写成 `T0.csv`（§5.2）。
- 原始 REW 工程文件（.mdat）与导出文本一起交回，**不删不改**。

### 4.6 现场自查（测试员）与工具复核（PM）
- **现场只做人工规则**（不需要 Python）：§4.1 时间门、§3 线性门、每次测 R 时 REW 叠图看它和本会话 R 的 rep1 差别有没有比 R 自己三次之间的差别明显变大（"明显"= 超过 R 三次之间的最大差）；变大 → 查温度/麦/治具/有人走动，必要时停。
- **工具复核**：会话结束把目录（导出文本 + header.txt + T0.csv + 记录本照片）发回 PM，PM 合并与分析：
  `python3 sprint7/tools/s7_driver_pairing.py --import-rew <目录> --header header.txt -o DRV_<YYYYMMDD>.csv`
  `python3 sprint7/tools/s7_driver_pairing.py DRV_<YYYYMMDD>.csv --as-built T0.csv`
- 测试员若想在 Windows 上自己跑：装 python.org 的 Python 3.10+（安装时勾 "Add python.exe to PATH"）→ 命令行 `py -m pip install numpy`（**不需要 scipy**）→ `py sprint7\tools\s7_driver_pairing.py ...`。跑不起来不影响交付——发回即可。
- 工具 WARN 的处置：参考喇叭漂移 → 整批重测；两两距离 < 噪声底 → 改善治具后重测（否则是在噪声上配对）；退出码 2 → 按提示修文件格式，**不改数值**。

## 6. 计算：散布怎样随频率变（工具 [2][3]，PM/dsp 读，测试员不判）

- **复偏差**：每只每频点 `z = H/R`，参考 R = 全批逐频点**中位 dB** + **圆中位相位**。**插值与多次测量平均都在复数域做**（再取对数时沿频率解卷绕），不会因相位卷绕把反接当成"一般离群"（critic R3c MAJOR-5；自检 T14）。显示单位 dB-eq = 8.686×|ln z|（1 dB-eq ≈ 0.115 Np 幅度 ≈ 6.6° 相位）。
- **逐只分解**（[2]）：常数增益（dB）+ 线性相位（斜率 = 延时 µs，截距 = 外推到 0 Hz 的相位）+ 残差（随频率变的部分）。**截距（按 360° 取模）接近 ±180° = 疑似反接**（纯延时——哪怕是几百 µs 的粗延时——取模后截距接近 0°；自检 T14b）。
- **散布 vs 频率**（[3]）：1k…4k 每个 1/3 倍频程带的幅度 SD、相位 SD、总 RMS、去掉每只常数增益后的 RMS；以及"**每只一个常数增益能解释的方差比例**"。
- **怎么读**（方向性）：比例高 → 散布以常数增益为主 → 实数修整（现架构）本身有用；比例低 → 实数修整本身帮助小，路线 B 才修得了对共模的逐频幅相。**但配对值不值得做不由这个比例决定**——看 [5] 的逐批比较（§7）。

## 7. 配对 / 分档 / 现装配（工具 [4][4b][5]）

```
python3 sprint7/tools/s7_driver_pairing.py DRV_<YYYYMMDD>.csv --as-built T0.csv --out-dir <输出目录>
# 另一上位规则为主表：
python3 sprint7/tools/s7_driver_pairing.py DRV_<YYYYMMDD>.csv --as-built T0.csv --assign resid
# 候选权重表对比（候选，非冻结）：
python3 sprint7/tools/s7_driver_pairing.py DRV_<YYYYMMDD>.csv --as-built T0.csv --chebwin 35
python3 sprint7/tools/s7_driver_pairing.py DRV_<YYYYMMDD>.csv --as-built T0.csv --weights <候选表.csv> --weight-col <列名>
```

1. **离群**：score = 该只 RMS|ln z|；score > 中位 + k·1.4826·MAD（k 默认 3.5 [L4]）→ OUTLIER；相位截距（按 360° 取模）>90° → POLARITY?（查接线/该只极性，**别当坏品换**）；粗延时本身只可能标 OUTLIER，不标 POLARITY?。默认排除出配对池；池 <16 只 → 工具拒绝（退出码 2），补测/补货或 `--keep-outliers` 仅看预测。紧批（散布接近测量噪声）时 MAD 规则可能把正常尾部标出——交 CTO 看，不自动换货。
2. **配对**：池内两两算复偏差**向量**距离 D（分析区间 RMS|ln z_a − ln z_b|），**全局最小优先贪心**取 8 对（**贪心不是最优匹配**；需要时可再做精确匹配，另议）；剩下的是备用（按 score 升序 = 优先替补顺序）。
3. **上位**：两种规则都算，主表用 `--assign` 选的那种，另一种打印一行作比较：
   - `d`（默认）：对内距离 D 最小的一对 → 权重最高的位置对（冻结 Dolph-20：c7 {7,8} > c6 > c5 > c0 > c4 > c3 > c2 > c1）；
   - `resid`：该对在实数修整之后的残差（含对共模的相位/延时）最小的一对 → 最高权重（critic R3c INFO-14；合成数据上平均略好但非处处好）。
   位置对 {c,15−c} 是**物理位置**；功放通道→位置对的映射以极性 QA Phase A 实测为准；非镜像拓扑 → §2.3 停。
4. **修整**：每路一个实数、与频率无关的增益 = 去掉该对在轴和的带均 dB 偏差；新权重 = w8[c]×修整，再整体归一使最大 = 1.0。**只修对内平均幅度**；对内两只之差、相位/延时、随频率变部分都修不了；相位主导时这个修整可能略有反效果（自检 T16d：各带 −0.08…−0.36 dB，[L2 合成]）。改权重 = 冻结表改动 → dsp 重跑 F4/F5 子带 bit-exact 链 + 独立 critic + CTO；**工具输出只是提案**。
5. **预测**（[5]，[L2 模型 on L1 输入]）：±90° 1/3 倍频程带平均、两侧取较差（= DEC-S7-SIDE30-01 ① 的 R90 形式），**默认口径 7 带（1000…4000 Hz）**；各行：无误差参考（各向同性模型，**非上界**）/ 随机装配（Monte Carlo 中位与 P10–P90、7 带全 ≥ 目标的比例）/ 随机+修整 / 随机+路线 B 理想化 / **现装配 T0（+修整 / +路线 B）** / 配对（+修整 / +路线 B）/ 另一上位规则的配对+修整 / "解析 vs MC"第二轨核（Van Trees 2.208 + 有限总体修正）。
6. **逐批判读行**：
   - "配对+修整 在 随机+修整 中的百分位"：高 = 本批配对确有收益；中低 = 本批配对不值得（即使一般统计上配对平均更好）；
   - "现装配 在 随机装配 中的百分位"：现装配是运气好还是差——恢复 vs 重配的直接依据之一。
7. **注意**：配对/现装配行是**单一确定装配**；配对行含选择偏差（按含噪实测挑最像的）；高于无误差参考的格子是误差恰好相消的巧合，工具会注明，**不可当可实现值**。这些数只用于**相对比较**，**不是**远场现场读数的期望值（模型不含喇叭指向性与其离轴离散、箱体、反射、功放通道差、阻抗分压）。路线 B 理想化 = 每路把对共模逐频修平、权重不变，**不是**路线 B 的上界。
8. **无误差参考低于目标** → 工具 WARN：在本模型下配对再好也到不了，权重表是另一个决定。

## 8. L 级规则（写结论时逐条对照）

| 项 | 定级 | 说明 |
|---|---|---|
| 逐只幅度/相位实测值、重复性、参考喇叭漂移 | **[L1 治具实测，限头块所记条件]** | 头块缺键 → 写"条件未记录"，**不定 [L1]** |
| 退路 C 的幅度 | [L1 治具实测，幅度-only] | 相位一律写"未测" |
| 就地近场初看（§4.0） | [L1 就地近场，受串音污染，只作相对初看] | 只取对内差 |
| 散布 vs 频率、离群/疑似极性、配对表、修整量 | [L1 输入的确定性计算] | 算法见 §6–§7 与工具源码；阈值 [L4] |
| 侧抑预测（无误差参考/随机/现装配/配对/路线 B） | **[L2 模型 on L1 输入]** | 只作相对比较；不得写成柱体侧抑"实测"或规格 |
| 现装配预测 vs 现装配远场基线 | 对照，**不互相替代** | 差异大 → 记录，模型外因素（指向性、箱体、功放通道、反射）逐条排查；不得用 [L2] 改写 [L1] |
| "配对后侧抑能到 xx dB" | **禁止**这样写 | 柱体侧抑只能由远场自由场测试给 [L1]（`S7_SIDE30_FARFIELD_TEST.md`） |
| "配对一定比随机好 / 一定不如随机" | **禁止**写一般结论 | 以本批逐批比较为准 [L2 on L1] |
| PM 侧 MC 结论 | [L2 on L4 散布假设] | 本实验数据回来后以本实验为准；冲突 → 铁律四强制重审 |
| 治具响应本身 | 不定级、不报告 | 在相对批参考中抵消 |
| 现场门的暂定阈值（`G_TIME`/`G_LIN`/N） | [L4 暂定] | CTO 可改；PM 用实测重复性复核 |
| 未做/未记录项 | 写"**未记录**" | 禁止事后补填、禁止推测替补 |

## 9. 失败处理

| 现象 | 处理 | 禁止 |
|---|---|---|
| 时间门不过（§4.1-3） | 按退路 C 继续，头块写 `timing_reference: none`，结论写"相位未测" | 不硬用相位 |

| 参考喇叭漂移 WARN / 现场 R 叠图明显变大 | 查温度/麦/治具/有人走动 → 整批重测 | 不挑"好的那几只"交 |

| 某只 POLARITY? | 功放断电、治具线拔下，按 §2.2 电池法复核该只 + 治具接线；确认反接 → 改线重测该只 | 不改数据符号；不当坏品换 |
| 某只 OUTLIER | 记录，交 CTO 决定换不换 | 不删数据行 |
| 拓扑停止门触发（§2.3） | 停，原样发回 | 不按配对表重装 |
| 擦圈/异响/发热 | 立即停该只（C10-8） | 不继续加电平 |
| 工具退出码 2 | 按提示修文件格式/网格/覆盖 | 不改数值 |
