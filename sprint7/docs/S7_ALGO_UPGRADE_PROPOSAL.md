## 3. 候选逐项评估

### B1 EQ + 保护限幅（O1）接入固件

- **预期收益**
  - 完成 DEC-S5-EQ-O1-01 要求的功能件（冻结令例外）；把 O1 成本从 [L4] 29–60 MCPS / [L2-account] 14.4–55.2 MCPS 升为 **[L1]**（EQ-on/off 的 `beam_cyc` 差 = O1 墙钟成本，可对照 T2 账**固定侧** O1 60 [L4] 的墙钟等价；T2 **争用侧**预留 `O1_contention_reserve=15` [L4] 须 H2 型 both_max−base 另测，B1 不坐实它）。
  - 限幅器完成"防烧功放"的**结构**；绝对阈值仍 [L4]（线③厂家函 Xmax/热额定无回函）。
  - 声学收益本轮**无法仿真**：EQ 段数与系数取决于 R3 在轴响应，本轮只能"结构 + 占位默认关 + unity 负控制"。
- **算力代价**（墙钟，`S7_DSP_ASSESSMENT.md §1.2`）
  - **不迁定点，保持 float32**：SHARC+ 原生浮点，转换只在 mono 边界 128 次/帧 ≈ 256 cyc [L3]；限幅在 Q31 整数域做，无需 8 通道转换；定点 biquad 会新开截断级并带一整套验证面，违背 [ASSUME-A2] 精神。
  - 合计 **6,728 [L3] – 52,352 [L4] cyc/帧 = 5.05–39.3 MCPS** → 墙钟余量 **1.592×–1.510×**（高端 = 到线余量的 90%，刀刃）。
  - 摆位：master-bus EQ 在 mono 输入进入 8 通道循环之前；限幅在 synthesize 之后、写 TX 之前，`t_ch[c] = t_base·w[c]`，`w` 取自同一张 `g_dolph_w8_q15`，chmap 开启时用同一下标（阈值随物理位置走）。
  - **headroom 交互 [L3]**：冻结链有 −4.8 dB 输入 headroom 契约；EQ 若有正增益会吃掉它 → 节点① 回量化饱和（PF-4 病根）。EQ 峰值增益 ≤ headroom 或补偿衰减须写进系数约束。
- **冻结件影响**：**零触碰**；F4/F5/F7/H1/H2 不需重跑（bench 工程不含 M2 TU）。新增的是 FG：①宏默认关 = 预处理输出逐 token 等同现固件；②宏开 + unity 系数 + `t_base=1.0` ⇒ 输出**逐位等同**现固件（板上样本 24-bit 左对齐，float32 尾数 24 位可逆；**桌面用冻结 chirp 做此负控制会假 FAIL**，须先 `& 0xFFFFFF00`）；③非 unity 时输出必变；④限幅：unity/满量程时 `lim_clip_count=0`，灌满幅时 >0；⑤FG 峰值取**限幅前**值（否则限幅掩盖 FIRA 逐帧失败特征，§4B #2）。
- **验证方式**（`S7_VERIFICATION_PLAN.md §1`）
  - 桌面：`eq_test`→`eq_verify.py`（现存，`eq_out.txt` 待生成）；适配层 `_Static_assert` 契约；旁路等价（host M2 帧链 + EQ 旁路 → 八锚逐位）；EQ 激活 vs scipy float64 参考 ≤1e-4；限幅数字门；Q31↔float 往返；guard-check 新配置 `-DM2_O1_EQ`。
  - 上板：指纹 `g_m2_o1_built`；运行时 `g_m2_eq_bypass`（JTAG 可切，单二进制 A/B）；独立括号 `g_m2_eq_cyc_*`；`g_m2_lim_clip_count[8]`、`g_m2_lim_out_max_abs[8]`；闸门顺序 M1 → M2 基线 → B1 旁路（读数应 = 基线）→ unity（`fg_eq_live=0` 正控制）→ 测试 biquad（`fg_eq_live=1`，`beam_cyc_max+eq_cyc_max < 1,333,333`）→ **限幅数字门在功放断电下过** → 上电最小音量听。
  - 台前：单变量 `g_m2_eq_bypass`：方向图不变性（master-bus LTI 不改方向图；30°/90° 两臂差 ≤ 地板）+ 在轴变化方向与设计一致。
  - **必须等 R3/线③**：EQ 段数与系数、`t_base`、EQ 后 SPL 口径。
- **风险与前置依赖**
  1. 墙钟刀刃：高端估计 1.510×；B1 之后再加 B2 必越线 → **前置 = B6.3 拆清 831k**，否则 O1 实测数不可解释。
  2. 限幅掩盖 FIRA 逐帧失败特征 → FG 峰值取限幅前（已进摆位）。
  3. `t_base` 默认 1.0 = 结构在、保护不在，须明示；不得把测试用 0.8f [L4] 带进产品 build（违 C3 精神）。
  4. unity 上板只证"接线不坏"，不证"EQ 有用"。
  5. 与 B2 共享 headroom 与插入点，须一并记账。
- **建议：本轮做**，顺序在 B6.3 与 B6 基座之后。一句话：B1 本身就是冻结令解冻条件的实测触发器，先把 831k 拆清，它的实测数才有意义。

  - **chmap 权重置换等价性被破坏**（`m1_loopback_tdm.c:385-387`）。数值坐实 [L2]（`S7_ACOUSTIC_SIM_REPORT.md §6.2`）：只置换权重不置换延时 → 焦点处损失 **4–13 dB**（4k@2m 从 +4.85 变 −8.51；6k@3m 从 +4.92 变 −8.29），焦平面 −6 dB 宽度扩 2.3–2.5 倍或主瓣分裂成等高离轴瓣，方向图逐点差 40–57 dB；broadside τ=0 时两者逐位相同（v1 等价性成立的控制）。**重推方案**：延时表按物理位次建，与权重用**同一个** `s_m2_chmap[c]` 取下标，"置换 (w,τ) 对"恢复与置换 TX 槽的位等价。
  - 需要新 golden 与 FG（延时表双轨、`focus_differs`/`zero_recovers`、同态 snapshot/restore、扩 `gen_f5_goldens.c` 同型生成器）。
- **验证方式**（`S7_VERIFICATION_PLAN.md §2`）：桌面 h1_host_test 同型 4 项 + 延时表双轨 + ST1-E + chmap 耦合断言 + 预测差表；上板指纹 `g_m2_focus_built`、`g_m2_focus_on` JTAG 切、独立括号；台前单变量 `g_m2_focus_on`：焦点（2–5 m）vs 远点（≥8 m）@4k，"开−关" ≥3 dB 才算数，**前置 P2 + P1 已闭合**；R3：效能 L2→L1。

  3. 前置 = 自家阵列极性 QA（相干叠加对极性比 broadside 更敏感）。

### B3 偏转

- **预期收益**：现板为零。声学侧不给偏转 ROI（属独立立项材料）。
- **算力代价**：**不是算力问题**。{c,15−c} 对称串联 → 阵因子 Σ w_c·2cos(k x_c sinθ) 为纯实偶函数，无法施加非对称相位（DEC-S3-DSP-03；DEC-S5-STEER-V1-01 FLAG-A [L1]；m3 三轨机器精度等价证明）。硬件叉 = 16 通道独立驱动（DAC ADAU1962A 12ch 不够 16、功放 8→16、转接板全改，Gate-2 级不可逆）；16ch FIRA 无板测，naive 2× 现墙钟 = 1.66M cyc > 帧预算 [L3]。**栅瓣约束 [L3]** fc(θ)=c/(d(1+|sinθ|))：0° 6,236 / 10° **5,314** / 20° **4,647** / 30° **4,158 Hz**——偏转 30° 时干净带上限已压到 v1 有用带（≥4 kHz）边缘；任何偏轴 PRD 自动触发 SC-S3-GEOM-01 d 重议。
- **冻结件影响**：若立项，几何变 → 一切几何相关冻结件重做；不在本轮。
- **验证方式**：现硬件**无法验证**（`S7_VERIFICATION_PLAN.md §3`）；灌"偏转权重"到 8 路配对拓扑只会测到对称图，不建议花台前时间；只能 [L2] 探索仿真（不进 log）。
- **风险与前置依赖**：把"余量 1.6×"读成"偏转是固件功能"= 类别错误；前置 = CTO 独立立项 + Gate-2 硬件叉 + d 重议 + Stage 5 硬件（无进展）。
- **建议：不做**。一句话：现板上偏转在数学上是零，不是慢。

### B4 低频指向性

- **预期收益**（`S7_ACOUSTIC_SIM_REPORT.md §5`，全部 [L2/numpy]，边界 [L3]）
  - 物理边界：L/λ = 0.60 (250 Hz) / 1.20 (500) / 1.80 (750) / 2.41 (1k)；常规加权最窄 = uniform 一列（1k 27.2°）。
  - 算法层在**假设**鲁棒性地板 WNGn ≥ −10 dB 下能做到：1k 波束宽 29.27° → **22.66°**（DI +0.8 dB）、750 Hz → 29.0°、500 Hz → 39.0°（DI +1.6）、250 Hz → 60.7°（DI +2.4）。
  - **不能做到**：无约束下限（1k 17.2°）需 WNGn −59 dB，物理不可实现；且所有超指向解 SLL 回到 ≈ −13 dB，**1k 的 30° 衰减只剩 13.1–13.5 dB → JY/T 1k/30° 从一级（现 23.1 dB）掉到三级**（门限 18/15/12）。"1 kHz 更窄"与"1k/30° 一级"在此模型上不能同时成立。
  - 与 EXP_COMPET 顶注里 [L3] 表述"1k 距超指向天花板仅 1.9 dB / WNG −43 dB"一致：本仿真 DI 增益上限 **+1.95 dB**，达 +1.9 dB 需 WNGa −40.8 dB（该表述的数值有本轮仿真 [L2] 独立出处，口径注明 WNGa；**仿真 L2，不为 EXP_COMPET 未落盘实测数字背书**——CTO D10 补，DEC-S7-RULINGS-02）。
  - 恒定波束宽（B5-2）不是低频变窄：BW(1k) 在所有设计里恒为 29.27°。
- **算力代价**（DSP 侧）：权重从 input-scale 移到子带级，4 张 8 权重表，960 mul/帧 → 8,171 [L3] – 48,000 [L4] cyc（6.1–36 MCPS），单项余量 1.517–1.589×；与 B1 高端相加 1.432× 越线。注意本树实现的交叉点是 **1.5k/3k/6k/12k**，不是标称 1k/2k/4k/8k；"低频"= sb0（<1.5k）+ sb1（1.5–3k）；要在 1 kHz 分界须改冻结核（不在本轮）。
- **冻结件影响**：不触碰冻结件；但 **F5 八锚的前提是 input-scale 权重** → 子带级权重需新 golden F5'（扩 `gen_f5_goldens.c` 同型，FG1 扩为 32 值互异 + 全 unity 坍缩到 F4 锚的负控制）；chmap 4 张表都按 `s_m2_chmap` 置换。
- **验证方式**：桌面能到全部算术（核 `tfb_*` 可跑）：F5' + 纹波 [L2] + 预测差表；上板：M2 板门 + `g_m2_sbw_sel` JTAG A/B + selftest；台前：≤1k 的改动效果落在 1.5 dB 重复性地板内**不可判**，只有 2k@≥8m 的恒定波束宽 A/B 可判；R3：绝对 BW/SLL、JY/T 各点。
- **风险与前置依赖**
  1. **WNG/散差敏感**：超指向权重放大阵元幅相散差；Dolph 基线 8 对 MC（±1 dB/±5°/±0.5 mm，N=3000，三轨）在 1k 已有 P(BW>30°)=5.3–6.3% [L2]，超指向下未仿真，方向只会更差。
  2. **差分金字塔纹波（结构性）**：`tree_filterbank.h:9-16` 明写各子带增益差异大时交叠区出现纹波；子带级权重 = 每通道各子带不等增益 → 8 通道纹波不同 → 波束在 1.5k/3k/6k 交叠区畸变。**必须先 [L2] 量化**。
  3. 前置 = P1 + P2；结论只能 [L2/L3]，L1 化卡 R3。
- **建议：本轮不做**。一句话：算法层能给低频的只有几度，而且要用 1k/30° 的一级达标去换；孔径才是低频的主因。
