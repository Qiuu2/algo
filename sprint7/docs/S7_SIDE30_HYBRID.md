## 0. 结论

1. **把 X3 的分频器换成线性相位 FIR 后，良率不变，X3 的方波冲高问题基本消失。**
   - **良率**：LPX3 与 X3 相同，也就是与每通道 FIR V1-128 打平（U-flat 装好直接用 21.2–21.3%，配对 + 微调 92.6%）。
     - 原因：两个低通各自复刻了 X3 的 LR4 低通幅度。三段的组合方式与 X3 不同（X3 用乘积，本结构用差，低、中两段最多差约 0.03），但频段增益重解之后，各路的等效幅度与 X3 几乎重合（最大差 1e-5 / 6.8e-4）。
     - critic R3g 用自己的代码、6000 个阵列复算：LPX3-b 与 X3 相差 −0.05 个百分点，在 U-flat 装好直接用这一格比 FIR 高 1.0 个百分点（χ² 4.7），所以"打平"是保守说法。
   - **削顶**：满幅方波下，各路峰值比现表同一路最多高 +1.3 dB（X3 +7.4 dB，FIR +0.4 dB）。保证任何满幅输入都不削顶，只需固定退 0.81 dB（FIR 5.0 dB，X3 10.5 dB）。
     - 这个退让是前提：不退的话，1 kHz 干净方波在 c7 已经到 +0.70 dBFS。
     - 所以**为了削顶，不必另加限幅器**；X3 那个"必须加联动限幅器"的理由，对 LPX3 不成立。
   - **但保护限幅器仍是待定项**：项目要求的逐通道保护限幅器（DEC-S5-EQ-O1-01，阈值 T_k = T·w_k）只在纯增益表下能保住加权比例。
     - 任何每通道滤波路线都有这个问题，**LPX3-b 与每通道 FIR 一样**：各路是不同的滤波器，限幅器在大音量时各自动作，会改变加权比例、恶化 ±90° 抑制。
     - 所以要做成联动的（各路检测、8 路同一增益），或者另定阈值规则。这是整条改架构路线共同的待定项，是新功能件，是否纳入例外清单由 CTO 定。
2. **算力** [L3 MAC]：
   - 精简版 LPX3-b（127 / 63 阶）：按对称折叠计 120 MAC/样点 = 7,680 MAC/帧，按直接型计 214 MAC/样点 = 13,696 MAC/帧。
   - 与每通道 FIR-128 × 8 比：折叠对折叠少 4.3 倍，直接对直接少 4.8 倍（放在 FIRA 上要看直接型）。比 X3（4,416）多约 74%。
   - 延迟 63 样点 = 1.31 ms，与 FIR-128 相同。精确版 LPX3-a（255 / 127 阶）指标几乎一样，算力与延迟都翻倍，没有必要。
   - 拆掉那棵树、换成它之后，总负载是升是降现在还判断不了，见 §3。
3. **5 kHz 观察带仍然弱**：LPX3 为 21 dB，与 X3 相同。加第 4 段（LPX4）能压到 38 dB，但正弦满驱动轴向会掉到 −4.48 dB，见 §2.3。**事后修正版** LPX4-cap 的表现：
   - 5 kHz 36.1 dB，轴向 −2.87 dB；
   - 良率比 LPX3 低：装好直接用低 1.4 / 2.1 个百分点（U / G），10 个格子里低 0–3.5；与 FIR 各格有高有低（−2.4 到 +1.5 个百分点），U-flat 装好直接用低 0.6（本脚本）/ 1.0（critic R3g）个百分点；
   - 正弦与干净方波下，所有通道都不比现表驱动得更重；按 L1 最坏情况最多高 +2.3 dB。
4. **与 FIR 相比仍然少的两样**：
   - **不能做逐通道相位校准**：每路每段只有实数增益。
   - **1 kHz 波束宽 36°**：FIR 为 32°。
5. **建议（PM 拟，待 CTO 过目）**：LPX3-b 取代 X3，作为"改架构"路线里省算力的那个候选，与每通道 FIR 并列。
   - 两者都要先定保护限幅器的联动方案（待 CTO）。
   - 最终二选一等三项结果：S-B（板上真实算力预算）、LPX 路径的台架周期测量、S-DRV（喇叭相位离散大不大）。

## 1. 结构

- **做法**：在单声道输入上算两个线性相位低通 FIR，h₁（700 Hz）和 h₂（1600 Hz）。三段取为 low = h₁、mid = h₂ − h₁、high = δ_D − h₂。短的低通在两端补零，与长的对齐到同一个延迟 D。
- **两条性质**：
  - 三段之和恒等于 δ[n − D]，即完美重建，与抽头长短、系数量化都无关；
  - 每一段都以 D 为中心对称，也就是线性相位、延迟相同。
- **等效关系**：每一路的滤波器 h_c = Σ_k w_k[c]·band_k 是一个长度为 N 的线性相位 FIR。但它不需要每路单独算：分频器只在输入上算一次，每路只做 3 次乘加的混合。
- **低通复刻 LR4 幅度**：h₁、h₂ 用最小二乘（scipy firls）设计，零相位幅度各自复刻 X3 在同一分频点的 LR4 低通幅度。拟合误差：精确版 ≤ 0.0002；精简版在 700 Hz 分频处 0.013，1600 Hz 处 0.005。
  - **注意三段的组合方式与 X3 不同**：X3 为 [A₁A₂, (1 − A₁)A₂, 1 − A₂]，本结构为 [A₁, A₂ − A₁, 1 − A₂]。低、中两段相差 A₁(1 − A₂)，最多约 0.03，出现在 1 kHz 附近。
  - 频段增益按与 X3 代表设计完全相同的稳健准则重解（低段固定 D20，η = 0.1，中间扇区 35–60°）。重解后，各路等效幅度与 X3 几乎重合（最大差 1e-5 / 6.8e-4，critic R3g 复核），良率因此相同。
- **用真实抽头检查**（只把会失败的算作检查）：
  - 各段严格对称；
  - 零相位响应的虚部 ≤ 1e-13；
  - 每个低通与 LR4 目标相差不超过 0.02。这是门限，用来抓 firls 设计失败；
  - 用设计出的增益和抽头核正前方响应：Σ_c 2h_c 与 δ[n − D] 相差 ≤ 3e-16。这一项抓不到"频段与增益对调"（对调后各段增益之和仍为 1/2），这条路径由 MATLAB 第 (4) 步独立重建各路抽头来覆盖；
  - KKT 的约束与最优性检查。
  - 另外，"三段之和等于 δ"是构造上的恒等式（三段伸缩相消），不会失败，列出来只作说明。
  - MATLAB 从存档抽头独立复核通过；critic R3g 另用自己的代码和变异测试复核。
- **与冻结子带树的关系**：树也是"共享分频 + 分带处理"，但它的细节带没有延时对齐，所以不能分带加权。本结构是延时对齐的版本。若进一步做成多速率（像树那样先降采样），算力还能再省，这一点没有评估。

**变体**：下面 4 个在看到任何结果之前就定好了，没有调参。

| 变体 | 分频点 | 抽头 | 设计目标 |
|---|---|---|---|
| LPX3-a | 700 / 1600 Hz | 255 / 127 | 7 个考核频段 |
| LPX3-b | 700 / 1600 Hz | 127 / 63 | 7 个考核频段 |
| LPX4-a | 700 / 1600 / 4470 Hz | 255 / 127 / 63 | 7 个考核频段 + 5 kHz 带 |

### 2.3 5 kHz 与第 4 段（含事后修正）

- **LPX4 的问题与原因**：LPX4 把 5 kHz 压到 38 dB，但正弦满驱动轴向从 −2.19 掉到 −4.48 dB。
  - **诊断**：第 4 段（4.47 kHz 以上）为了压 5 kHz，加权收得很陡：最大值 / 总和为 0.26，D20 为 0.155。而满驱动归一取全频段最大值，它出现在第 4 段约 100% 生效的高频平台上（约 10 kHz 以上直到奈奎斯特，具体落在哪一点由纹波决定；c7），于是所有频率一起被压低。
- **事后修正（LPX4-cap）**：让第 4 段的最大权重不超过第 2 段，做法是只给第 4 段加一个载荷，用二分法求出刚好满足约束的值。结果是 5 kHz 36 dB、轴向 −2.87 dB；良率比 LPX3 低：装好直接用低 1.4 / 2.1 个百分点（U / G），10 个格子里低 0–3.5；与 FIR 各格有高有低（−2.4 到 +1.5 个百分点），U-flat 装好直接用低 0.6（本脚本）/ 1.0（critic R3g）个百分点。
  - **仍差 0.7 dB 的原因**：第 2 段的最大权重在 1 kHz 附近从来没有 100% 体现出来，而第 4 段在高频是 100% 生效的，所以这个约束定得偏松。
  - 更好的做法可能是按"实际实现的最大值"来约束，或者在约 6.2 kHz 以上再加一段 D20（6.2 kHz 以上是栅瓣区，本来就不考核）。**这两种都没有评估。**
- 5 kHz 只是观察带，不在 30 dB 的考核口径里。要不要为它多花算力和轴向电平，由 CTO 定。

## 4. 局限与风险

- **保护限幅器**：项目要求的逐通道保护限幅器（DEC-S5-EQ-O1-01，T_k = T·w_k）只在纯增益表下能保住加权比例。LPX3-b 与每通道 FIR 都要把它做成联动的，或者另定阈值规则；这是新功能件，待 CTO 定（critic R3g F1；R3f 当时只对 X3 指出，漏了 FIR）。
- **不能做逐通道相位校准**：每路每段只有实数增益。若 S-DRV 显示喇叭相位离散大、随频率明显变化，可以给每路再加一个短 FIR 只做校准，也就是第二种 hybrid；或者直接改走 FIR。
  - 短校准 FIR 的算力：每路 16–32 阶时为 8,192–16,384 MAC/帧 [L3]。它能恢复多少良率，要用实测离散来评估。上表"复数校准"两列只是理想上限。
- **1 kHz 波束宽 36°**（FIR 32°），1k/30° 的带内最小值 14.3 dB 低于二级线 15（单频点为一级），这两点与 X3 相同。
- **假绿陷阱**：三段之和恒等于延时后的输入，与各段增益无关。所以板上验证必须逐通道比对，并准备一个会 FAIL 的占位对照（例如三段增益都等于 D20）。
- **定点**：三段 = [h₁, h₂ − h₁, δ − h₂]，即使系数量化，三段之和仍严格等于 δ，这是代数恒等。各路是普通的对称 FIR，定点数据通路的风险与 FIR 路线同类，未评估 [L4]。
- **事后变体**：LPX4-cap 是看到第一次结果后才加的，已在日志里单列。
- **模型局限**：同 `S7_SIDE30_ANALYSIS.md` §7。各向同性点源，±90° 是模型最不可信的掠射方向；误差模型是假设。
