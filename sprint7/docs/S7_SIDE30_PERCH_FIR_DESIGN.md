## 0. 结论先行（全部 [L2]，误差模型 [L4]）

1. **理想模型下，每通道 FIR 把 ±90° 1/3 倍频程抑制从 Dolph-20 的 ~23 dB 提到 ≥40 dB（1k/2k/4k）**，Dolph-35 单表为 ~37–38 dB [L2]。FIR 能在每个频率都把零点放在 90°，单表做不到。
2. **加公差后瓶颈是驱动器随机误差，不是波束设计。**
   - 未校准阵列 90°（较差侧）中位数 [L2]：FIR 各方案 31.3–32.6 dB，Dolph-35 30.5–30.7 dB，Dolph-20 21.8–22.5 dB。
   - 随机误差的平均旁瓣底 = σ²·‖w‖²/|Σw|²。等权时为 σ²/16 = 33.6 dB [L3 闭式，σ²=0.00698 取自 U-flat 抽样]，这只是等权的界。
   - 实际设计的底（1k/2k/4k，含 ±0.5 mm 位置项）[L2]：Dolph-35 为 32.7/32.6/32.4 dB，V1-128 为 33.1/33.0/32.8 dB，V2-128 为 32.8/32.9/32.8 dB。
   - FIR 各方案的底比 Dolph-35 高 0.1–0.7 dB，因为它们的 WNG 高于 Dolph-35（−0.92 dB）。但 FIR 的 WNG **不高于** Dolph-20：1–4 kHz 为 −0.17…−0.80 dB，Dolph-20 为 −0.17 dB。所以说"FIR WNG 更高"只对 Dolph-35 成立。
   - FIR 的设计残差（理想 ≥40 dB）远在底线以下。
   - MC 的单侧平均功率抑制 [L2]：V1-128 为 32.85/32.41/32.45 dB，Dolph-35 为 31.36/31.36/31.22 dB。较差侧中位数比单侧平均功率低 0.6–1.0 dB，所以"中位数约 32 dB"与底线自洽。
3. **联合良率（主口径：DEC-S7-SIDE30-01 ① 的 7 个 1/3 倍频程频带 1k/1.25k/1.6k/2k/2.5k/3.15k/4k 全部 ≥30 dB；括号内为 1k/2k/4k 三频带辅口径）[L2×L4]**：
   - 未校准（出厂）：FIR 16.9–23.0%（40.5–51.1%）；Dolph-35 6.0% / 8.1%（23.4% / 26.8%）；Dolph-20 0%。前一个数为 U-flat，后一个为 G-p0.5。
   - **现有架构（冻结树）上 Dolph-35 的公平对照是"夹具测量配对 + 增益修正"：82.8% / 56.8%（89.2% / 69.3%）。** 同一策略下 FIR 为 U-flat 90.2–92.6%（94.6–97.2%）、G 76.1–81.6%（84.4–88.9%）（critic R3b 二次 delta MINOR：按误差模型分列，与 Dolph-35 的分列对齐）。Dolph-35 的复数校准同样需要每通道滤波器，冻结树上做不了（DEC-S7-RETRACT-SUBBAND-01）。
   - 配对 + 复数校准：FIR 为 U-flat 100%、G 96.9–98.9%；Dolph-35 为 U-flat 100%、G 90.6%（Dolph-35 做复数校准同样需要每通道滤波器，现有冻结树上做不了）。
   - **7 频带口径下，FIR 在全部 90 个"同误差模型、同策略"对照格里都不低于 Dolph-35**：81 格严格更高；另 9 格是 U-flat 配对+复数校准，两者都是 100%。
   - 与 critic 独立 MC 对照（U-flat 出厂，3000 阵，seed 4242；本文 1000 阵）：7 频带 Dolph-35 5.4 vs 6.0%，V1-128 20.7 vs 20.4%，V2-128 18.4 vs 16.9%。差 ≤1.5 个百分点，在 MC 噪声内（约 1σ）。
   - **良率对阈值极敏感**：中位数就落在 30–33 dB。例如 Dolph-35 → V1-128 各频带出厂中位数只高 0.8–1.5 dB，7 频带联合良率却从 6.0% 变成 20.4%（U-flat）。
4. **V2（保护更宽的 45–90° 扇区）在 90° 处不比 V1 好** [L2]：同抽头数比较的 30 个 MC 格子里，7 频带口径 29 格 V1 ≥ V2（V1 最多高 5.6 个百分点；唯一例外 V2 只高 0.1）；三频带口径 27 格 V1 ≥ V2（−1.4…+7.0）。原因是 V2 的 WNG 更低。
5. **FIR 长度对 90° 良率影响很小**（64 与 256 抽头相差：7 频带 ≤2.9 个百分点，三频带 ≤4.8）[L2]，**但决定 V1 能否守住 1 kHz 窄束**：
   - V1 的 BW@1k 在 64/128/256 抽头下 = 35.3° / 32.4° / 29.5° [L2]。
   - 只有 256 抽头能同时满足 BW≤31° 且 8 个可评 JY/T 点全 1 档（12 点中 8 点可评，180° 不可评）。
   - 但 1k/30° 的余量很薄：频带值 18.55 dB 对 18 dB 门限只多 0.55 dB，单频值 20.06 dB，频带内最低 14.79 dB [L2]。
   - **30° 没做公差 MC，所以 30° 的 1 档不稳健。**
6. **代价**：
   - 轴向正弦满驱电平：V1 比 Dolph-20 低 1.6–2.6 dB，Dolph-35 低 2.47 dB [L2]。
   - 余量：等轴向增益时最坏通道增益比 Dolph-20 表高 +5.6…+7.8 dB。今天的链路已按 PF-4 约定留 4.8 dB 输入余量，所以 FIR 路径在今天基础上还要**再多 +0.8…+3.0 dB**（V1-128 +2.0 dB，V2-128 +3.0 dB）[L2]。
   - 群延迟增加 31/63/127 样点（0.65/1.31/2.65 ms）[L3]。
7. **算力**：128 抽头方案若放在核上，从"勉强"（对称折叠、30 cyc/MAC：0.98 M cyc/帧，仅 FIR 本身）到"超预算约 2.5×"（直接型、50 cyc/MAC：3.28 M）[L3×板证因子]。可行性取决于 FIRA 路径 [L4]，需要台架测量（L1，尚无）。

## 1. 目的

评估"替换冻结 4 子带金字塔、改为 8 路每通道线性相位 FIR"能否把侧向（±90°）抑制推向 30 dB，以及代价：束宽、JY/T 分档、轴向电平、算力、延迟、需要什么校准。只在桌面评估，不动固件。

背景（已验证事实，沿用）：
- 冻结金字塔（`tree_filterbank.c:139-205`）实际分割在 3k/6k/12k。它的细节子带是非延迟对齐的梳状残差，只有各子带增益相等时才完美重建，**所以在它上面做不了频变权重**。
- M2 现状 = 频不变 Q15 输入缩放权重 + 8 路恒等树（`m1_loopback_tdm.c:543-590`）。
- 本原型就是这棵恒等树的候选替代。

## 2. 方法

- **模型**（`s7_common.py`，只读导入，先跑 `assert_anchors()`，A1–A8 全过）：
  - 16 个各向同性点源，d=55 mm [L1 拆机]，远场，c=343 m/s。
  - 通道 c 驱动串联对 {c,15−c}，所以 AF(θ,f) = Σ_c H_c(f)·2cos(k·x_c·sinθ)，x_c=(c−7.5)d。
  - 8 路 FIR 群延迟相同，共同延迟在所有比值中抵消。
  - **未使用** `s7_common.SUBBANDS`（该表有误）。
- **逐频点鲁棒权**（0–24 kHz，2049 点，Δf=11.7 Hz）：
  - Q(f) = R_side + η·R_mid + λ·I；W = Q⁻¹a₀ /(a₀ᵀQ⁻¹a₀)，a₀=[2…2]，所以 Σ_c 2W_c ≡ 1（轴向平坦）。
  - R_side 取 [θs, 90°] 扇区平均；R_mid 取 [θm(f), θs] 扇区平均，sinθm = 1.2λ/(Nd)。
  - **λ = 2σ²(f)**（Van Trees 2002 式 2.208 / Gilbert-Morgan 1955 的均值性能加载）。σ²_gain = 0.00698（U ±1 dB、±5° 抽样），再加位置项 (k·σ_x)²（±0.5 mm）。
- **频段处理**：
  - 420→700 Hz 以下（对数频率上升余弦）过渡到冻结 Dolph-20：口径受限，低频行为与今天的 M2 一致。
  - 5.2→6.2 kHz 以上过渡到 Dolph-20：栅瓣区，90° 怎么做都没用。
- **跨频平滑**：Straube 2018 指出逐频最小二乘会得到粗糙的滤波器，所以在 log₂f 上做 Gaussian 平滑，FWHM 1/6 倍频程。粗糙度（W 对 log₂f 二阶导的 rms / 平均|W|，0.5–5.5 kHz）[L2]：V1 19.6→5.6，V1n 19.5→5.2，V2 22.5→5.4。
- **FIR 实现**：
  - 8 路 I 型线性相位 FIR，长度 63/127/255，归入 64/128/256 抽头档（末位补一个 0，群延迟为整数 31/63/127 样点）。
  - 加权最小二乘拟合平滑后的目标，并加**精确线性约束 Σ_c 2h_c[n] = δ[n−M]**，轴向平坦由构造保证。
  - 拟合度量 = Q/(WᵀQW)（相对超额侧向功率）+ 1.0·R_all/(WᵀR_allW)（0–90° 全方向图保真，用来守主瓣/BW），按 log-f 密度加权。
  - **仿真结果** [L2]：max|Σ2h−δ| ≤ 7e-13（内存 float64）；CSV 系数只有 11 位有效数字，回读后复现到 2.0e-12。轴向纹波（浮点）≤ 6e-11 dB，Q15 量化后 ≤ 0.0017 dB。
- **三个方案**：
  - **V1「守 1 kHz 窄束」**：θs=60°；1 kHz 不压中区（η=0），1.15→1.7 kHz 渐入 η=0.05，保证 2k/4k 的 30° 为 1 档。目标"BW@1k ≤ ~31°"出自协调者任务书；参照线是旧内部线"BW(−6 dB 全角)@1k ≤ 30°"，PRD v2.4 起已降为工程参考，不是承诺（`prd_update.md:111,120,165`）。
  - **V1n「短 FIR 窄束」**：同 V1，但保护扇区在 0.8 kHz 以下从 80° 起，1.3 kHz 以上放开到 60°。作为取舍对照组。
  - **V2「最大侧向」**：θs=45°，η=0.02。
- **评估对象是实际 FIR**，不是逐频点权：
  - 1/3 倍频程 250 Hz–6.3 kHz（每频带 31 点功率平均）的 att90（较差一侧）、60–90° 扇区最差值、att30、WNG、误差底；BW(−6 dB 全角，单频)；轴向满驱电平。
  - JY/T 各点同时给出频带值、单频值和频带内最低值。
  - **JY/T 阈值出处**：`sprint3/audit/std_table9_compliance.csv`（L1_thr/L2_thr/L3_thr 列）= PRD v2.4 §3.1 的 12 点口径（`prd_update.md:108-111`，30°/90°/180° × 500/1k/2k/4k）。
  - 脚本 `JYT` 字典（py:88-95）即取自该 CSV。180° 的阈值为 500 Hz 12/10/8，1k/2k/4k 各 20/17/14。
  - **180° 这 4 点在本模型中不可评**：各向同性线阵前后辐射相同（R9），所以只报"NA"，不参与分档。**下文"最差档"一律指 12 点中可评的 8 点。**
- **Monte Carlo**（每格 1000 个阵列，各方案用同一批随机数）：
  - 口径复刻经 critic 验证的 `critic2/mc2.py`。两个误差模型：U-flat（±1 dB/±5°/±0.5 mm）；G-p0.5 + 夹具 0.25 dB/1.5°（方差相同，其中 50% 方差按 1 倍频程相关沿 log f 平滑重抽）。
  - 五种策略：出厂 / +每通道增益修正 / +夹具测量配对+修正 / +每通道复数频变校准（不配对）/ 夹具测量配对+复数校准。
  - 指标：±90° 较差一侧的 1/3 倍频程功率平均。另外记录单侧平均功率抑制，用来和误差底对比。
  - 联合良率两种口径：**主口径**为 DEC-S7-SIDE30-01 ① 的 7 频带（1/3 倍频程 1k–4k 共 7 个频带全部 ≥30 dB）；辅口径为 1k/2k/4k 三频带（任务书原口径）。
  - **MC 锚点**（三频带口径，与 critic 参考同口径）：Dolph-35 须在 ±8 个百分点内复现 critic 参考值，**8/8 全部 PASS**。U-flat 为 23.4/48.1/89.2/100（参考 26/47/91/100）；G-p0.5 为 26.8/36.3/69.3/92.4（参考 24/40/65/93）。
- **近场**：麦克风放在阵列轴延长线上距离 r 处，与法线上同距离 r 的点比较，用精确点源距离，r = 1/2/4/8/16/1000 m。给出 1/3 倍频程频带值和单频值两种口径。

## 3. 假设与局限（必读）

1. **各向同性点源、远场、无障板/箱体衍射、无单元指向性、无互耦。**
   - **±90° 是沿箱体的掠射方向，正是本模型最不可信的角度。** 箱体衍射/遮挡、振膜与箱面相互作用都可能填掉模型里的 90° 零点。
   - 模型里 90° 零点的深度（40–50 dB）**不能当作可达值**，只能用于方案间相对比较。
2. **误差模型为 [L4]**：只有均匀/高斯的幅度、相位、位置三项。尚无单体频响离散度的 L1 数据；单体老化与温漂未建模。
3. **复数校准按理想处理**：按夹具网格插值得到 1/pm，直接乘到通道响应上。真正实现要把校准滤波器卷进 h_c，这会带来：
   - **增加抽头数和 L1 增益**，§6-4 的余量数字不含这部分；
   - **需要每台一套系数**（数据管理、版本确认）；
   - **校准后的系数不再满足 Σ2h=δ**：轴向平坦改由"电 + 声"整体保证，因此 Σ2h=δ 只适用于未校准的设计系数。

   Dolph-35 的复数校准同样要每通道滤波器，在冻结树上做不了（DEC-S7-RETRACT-SUBBAND-01）。**所以现有架构的公平对照是 Dolph-35"夹具测量配对 + 增益修正" 89.2% / 69.3%**，不是它的复数校准行。
4. **良率对阈值极敏感**（§0-3）。良率只宜用于方案间相对比较（共用随机数使差值稳健），不宜作绝对承诺。
5. **联合良率的主口径是 DEC-S7-SIDE30-01 ① 的 7 频带**（`prd_update.md` v2.5：1/3 倍频程 1k/1.25k/1.6k/2k/2.5k/3.15k/4k 逐频段 ≥30 dB）。1k/2k/4k 三频带口径（任务书原口径）只作辅列。
   - 新增的 4 个频带用同一批随机抽样求值：抽样次数与频率网格无关；夹具测量、配对、校准仍在原网格上。所以三频带数字逐字节不变。
   - 7 频带良率明显低于三频带，因为要 7 个频带同时过线。
6. **近场**（点源几何，1/3 倍频程频带值，41 点）[L2]：

### 4.3 主要取舍

**窄 1 kHz 束、短 FIR、30° 1 档三者不能同时满足** [L2]：
- V1 要满足 BW≤31° 与 8 个可评点全 1 档，需要 256 抽头；而且 1k/30° 余量只有 +0.55 dB，没做公差 MC，不稳健。128 抽头时 BW 为 32.4°，64 抽头为 35.3°。
- 128 抽头下若硬守 29°（V1n），1k/30° 降到 2 档（17.65 dB，仍在 2 档保底承诺内），1 kHz 的 60–90° 扇区只剩 26 dB。
- 侧向 90° 在所有方案里都受公差底限制（出厂中位数 31.3–32.6 dB），与方案和抽头数关系很小。
- 真正抬高良率的是**生产工艺**：夹具测量配对（在增益修正基础上，7 频带 +32.5~59.8 个百分点，三频带 +18.0~41.1）和复数校准。

## 5. 算力与延迟

| 项 | MAC/帧（64 样点 × 8 通道）[L3] | 核上 cyc/帧 @30–50 cyc/MAC [L3×板证因子] | 备注 |
|---|---|---|---|
| 冻结树，C 参考代码计数（每次推入都做 63 抽头全卷积，`tree_filterbank.c:83-205`） | 169,344 | —（不适用） | **这是 C 代码的计数。M2 实际在 FIRA 上跑树（`fira_tfb_analyze/synthesize`），不执行这个数** |
| 冻结树，高效实现（多相 + 半带跳零，33 个非零系数） | 44,352 | — | 3×56×33×8 |
| FIR 64，直接型 / 对称折叠 | 32,768 / 16,384 | 0.98–1.64 M / 0.49–0.82 M | 群延迟 31 样点 = 0.65 ms |
| FIR 128，直接型 / 对称折叠 | 65,536 / 32,768 | **1.97–3.28 M / 0.98–1.64 M** | 群延迟 63 样点 = 1.31 ms |
| FIR 256，直接型 / 对称折叠 | 131,072 / 65,536 | 3.93–6.55 M / 1.97–3.28 M | 群延迟 127 样点 = 2.65 ms |

- **板证因子 30–50 cyc/MAC 是项目强制规则**（`.claude/skills/dsp-algorithm/SKILL.md:57,69`；`decisions_log.md:234`）。50 端是 [L4] 板包络（`S7_DSP_ASSESSMENT.md:90`）。对称折叠行按乘法数计，折叠前的加法未另计。
- **8.51 cyc/MAC** 来自 H1 的 8 抽头平坦整数核，是另一类核，只作 [L3] 参考。按 `S7_DSP_ASSESSMENT.md:90` 的先例，**它的低端不是下界**，本文不用它算周期。
- **帧预算 1,333,333 cyc 以 CCLK = 1 GHz 为前提。** DEC-S7-RULINGS-03 规定须用板上读回的实际 CCLK 重算帧预算和余量；读回仍待完成，所以下面的比值随之待定。M2 今天墙钟 830,903 cyc/帧 [L1]，含 FIRA 忙等。
- **比较口径的缺口**：上表只算 FIR 本身。①没计入 M2 中树以外的负载：输入加权、TX 交织、FG 扫描、ISR 等；②树的 169,344 是 C 代码计数，不是 M2 的实际执行量。
- **结论** [L3×板证因子；FIRA 部分 L4]：128 抽头折中方案若放在核上，从"勉强"（对称折叠、30 cyc/MAC：0.98 M = 预算的 0.74×，还没加非 FIR 负载）到"超预算约 2.5×"（直接型、50 cyc/MAC：3.28 M = 2.46×）。**可行性取决于 FIRA 路径 [L4]，需要台架测量（L1，尚无）。**
- **FIRA 适配性 [L4，不做周期声明]**：8 路直通 FIR 是 FIRA 的原生负载，比每通道 9 级抽取/插值半带结构简单。I/O 契约见 §6-3。

## 6. 落地需要什么（均需 CTO 架构裁定，本文不做决定）

1. **架构替换**：
   - M2 中每通道"输入缩放 Dolph 权 + `fira_tfb_analyze/synthesize` 恒等树"整体换成"每通道 FIR h_c"，权重折进 FIR，Dolph-20 表退役为 FIR 系数表。
   - 这会**动冻结链**：`fira_tree.c` CALL-ONLY、`g_hb63` 系数、M2_SELFTEST 八锚点 / 6 宏指纹、M2_SEG_CYC 四段括号都要重立。
2. **新 golden**：
   - 8×L 系数表：同源生成器 + 上电逐值核对，沿用 hb63 的纪律。
   - host 定点与浮点逐位对账。
   - 逐通道冲激 / 扫频 golden。
3. **验证计划（FG1 / FG2 / IO1 / ST1）** [L2 数字]：
   - **FG1 求和恒等陷阱**：Σ_c 2h_c ≡ δ，所以 8 路输出之和按代数恒等于延迟后的输入，与金字塔的 PR telescoping 同类。**对"通道求和"做端到端 CRC/比对，验不了滤波。** 必须逐通道比对。
   - **激励与 golden 必须覆盖 0.7–5.2 kHz**，这是鲁棒设计占比为 1 的频段。
     - 在 0.42–6.2 kHz 以外，设计目标就是 Dolph-20 表 × δ。
     - 实际 FIR 与"全用 Dolph 表"占位版的差距（最大偏差 / 最大权，dB）：20–300 Hz 为 −3.6…−26.5，6.2–8 kHz 为 −12.8…−31.5，8–20 kHz 为 −14.3…−35.2；0.7–5.2 kHz 为 −3.3…−4.1（`s7_fir_verify.csv`）。
     - 能否区分取决于测试容差：**容差比"与 Dolph 表占位版的差距"更宽的测试区分不了二者**。
     - 逐值对 golden 的比对能轻易抓出 −26…−35 dB 量级的差异；64 抽头在低频离占位版也有 −3.6 dB，同样可以区分。
     - 仍保留 0.7–5.2 kHz 覆盖要求：这一段差距最大（−3.3…−4.1 dB），占位版在这里最容易暴露。
   - **FG2 占位版必须 FAIL**：至少跑恒等、δ/16 均匀、全用 Dolph 表三种占位版，证明它们在 0.7–5.2 kHz 的逐通道比对上都 FAIL。
   - **Σ2h=δ 永远不能当系数检查**：均匀 δ/16 也能通过（max|Σ−δ| = 0），但波束完全不同。系数须逐值对 golden。
   - **ST1 跨帧状态**：若 FIRA 调用无状态，64 样点帧之间必须带过 L−1 个历史样点：63/127/255 抽头分别为 62/126/254 个。
   - **IO1**：
     - (a) 每段输入须 ≥ ntaps+window−1 个**已初始化**样点：127 抽头为 190；若加载补零后的 128 抽头槽则为 191（63/64 抽头为 126/127，255/256 抽头为 318/319）。
     - (b) 恰好填满 out_count = 每通道每帧 64 个样点（无抽取，不得半填或重复抽取）。
     - (c) 8 个通道段之间清零共用 scratch；DMA 输出在读取前使 cache 失效。
4. **定点余量**（等轴向增益 = 今天 M2 的 Dolph-20 表，最大权 1.0）[L2]：
   - **FIR 最坏通道增益（L1）为 +5.6…+7.8 dB**（V1-128 +6.76，V2-128 +7.75），正弦最坏增益为 +1.6…+3.7 dB。
   - 今天的树链路已有 PF-4 约定的 **4.77 dB 输入余量**（半带 Σ|h| = 1.7309，`sprint3/dsp/pf4/WO_node1_saturation_fix.md:40`）；树的输出本身按 PR 不超过输入。
   - 所以 **FIR 路径在今天基础上还要再多 +0.8…+3.0 dB 输入余量**（V1-128 +2.00，V2-128 +2.99；`s7_fir_headroom.csv`）。这还没算 §3-3 校准滤波器带来的 L1。
   - **核上 Q15×Q31 格式**：
     - 等增益下最大系数为 1.027–1.038，**超过 Q15 上限**，需要 Q14（多 1 位移位）或预缩放。
     - int64 累加器峰值 47–48 位 ≤ 63，不会溢出。
     - Q31 输出窄化必须饱和（同 PF-4 FIX-01）。
   - **FIRA 格式**：
     - 项目现有 FIRA 路径用**定点模式**（`fira_tree.c:16`，`adi_fir_FixedPointEnable(SIGNED)`，int32 系数 + 核侧 postscale >>15 + 核侧饱和），同样有系数范围和输出饱和问题。FIRA 定点模式的内部累加宽度为 [L4]，本文未查。
     - 若改用 FIRA 浮点模式（本项目未用过），内部不会溢出，只有浮点→Q31 转换需要这个界。
5. **生产流程**：
   - 夹具逐只测量 16 只单体后配对，再做每台复数频变校准：夹具测量 → 卷进 h_c，得到每台一套系数（后果见 §3-3）。
   - 涉及数据管理与版本确认；上板属硬件不可逆动作，需走 C10/铁律九清单。
6. **轴向 SPL 代价**：V1 比 D20 低 1.6–2.6 dB [L2]。与对外 ≥90 dB 承诺（内部口径 94.0 dB [L2 待消声室]，余量约 4 dB）叠加后，需要重新核账。

## 7. 开放问题

1. **实物 ±90° 掠射方向是否存在可利用的零点**：箱体衍射与单元指向性需要 L1 实测，是否外租消声室由 CTO 定。**这是本方案是否成立的第一前提。**
2. 真实单体幅相离散度及其频变程度，用来替换 [L4] 模型。可借极性 QA / 夹具数据。
3. 30° 公差 MC 未做：30° 的 1 档（尤其 V1-256 的 1k/30°，余量 +0.55 dB）是否稳健。
4. 对校准后残差（反对称对内项）重新设计 λ 能否再深，本文未做；校准滤波器的有限长度、L1 与每台系数也未计入。
5. BW@1k≤31° 是否为硬指标。若是，只能用 256 抽头（算力/延迟见 §5）；否则 128 抽头 V1 是折中。PRD 口径：旧 30° 线已降为工程参考。
6. 板上 CCLK 读回（DEC-S7-RULINGS-03）与 FIRA 上 8×128 抽头 FIR 的真实周期数、I/O 契约（需台架测量，[L4]）。
