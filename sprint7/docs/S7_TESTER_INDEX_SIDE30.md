## 0. 开始之前（每次都做）

1. 在仓库根目录执行 `git pull`，然后执行：
   ```
   git merge-base --is-ancestor 04e0e6a HEAD && echo OK
   ```
   - 打印 `OK` 才继续；没有打印就停下，把结果发回。
   - 若 `git pull` 提示 `local changes would be overwritten`，原样发回，**不要 reset**。
2. 硬件安全一律按 `sprint3/audit/BENCH_OPS_CARD.md` 第 8–12 步：
   - **供电**：确认 JP1 的供电方式；先目视检查无短接、确认电压，再上电。
   - **BMODE0/1/2 全部拨到 0**（No boot）。
   - **上电顺序**：先插 JTAG（板子断电状态）→ 板子上电 → 再接仿真器 USB；禁止热插拔。
   - **下电顺序**：先在软件里 disconnect → 断电 → 拔线。
   - **改接线、换喇叭、做电池测试之前**：先断功放电源，或拔掉功放输出。
3. 每一张回填表都要附上两样东西：
   - **build 指纹**：`.map` 文件，以及 Defined symbols 的截图；
   - **现场条件记录卡**：日期、地点、仪器、距离、高度、信号、电平、本底、天气。

## 2. 先后关系

- **① 与 ②**：可以任意先后，也可以同一天做。

- **⑤**：③ 做完（或 CTO 书面豁免）、`V_JIG_MAX` 填好、C10 签字之后再做。

## 3. 三条不许碰的线

1. **驱动上限**：`V_FF_MAX` 和 `V_JIG_MAX` 这两格没由 CTO 填好之前，对应的会话**不开工**。
2. **拆喇叭**：没有 CTO 签字的 C10 清单，不拆、不改线、不换位置。
3. **接线拓扑**：极性 QA 如果发现某一路推的不是对称的一对（{c, 15−c}），立刻停，原样发回，不要按执行单继续。
