## 0. 结论

1. **低阶 IIR 分频加权在 7 个考核频段的良率上与 128 阶每通道 FIR 打平，MAC 数只有其 1/7–1/15；但它的瞬态余量明显差，要靠一个联动限幅器（新功能件，待 CTO 定）。**
   - **结构**：在单声道输入上跑一组共享的 Linkwitz–Riley（LR）同相分频器，分 3 段（700 Hz、1600 Hz 两个分频点，LR4）。每一路输出等于三段信号的加权和，即一个 8×3 的增益矩阵。低段固定用现表 D20，中、高两段按与稳健扇区表、FIR 原型相同的稳健准则联合设计。
   - **7 频段良率** [L2 on L4 spread]，格式为 U-flat / G：

     | 设计 | 装好直接用 | 配对 + 微调 |
     |---|---|---|
     | 本结构（X3-LR4） | 21.3 / 25.1% | 92.6 / 80.8% |
     | FIR V1-128（对照） | 20.4 / 22.0% | 92.1 / 79.5% |

     critic R3f 做了配对检验（它重建的 V1-128 逐格复现 CSV）：U-flat 装好直接用 +0.9 个百分点（p = 0.45），配对 +0.5（p = 0.70），换新种子结果相近，所以是打平；G 装好直接用 +3.1（p = 0.008），X3 略好。
   - **代价** [L2]：
     - **瞬态余量**：两段分频的相位是一个公共全通，轴向**幅度**平坦、**相位**不是线性的（群延时 0.92 ms @ 直流 → 0.72 ms @ 1 kHz → 0.07 ms @ 4 kHz）。所以按正弦满幅归一后，方波类信号在各路会冲过去。
       - 满幅方波（含起始段）下，各路峰值比现表同一路最多高 **+7.4 dB**（1 kHz 方波，c2）；按绝对电平，c6 超过数字满幅 +5.0 dB、c7 超过 +4.8 dB；
       - 同一测试下 FIR V1-128 ≤ +0.4 dB；
       - 粉红噪声下两者都低于现表（X3 ≤ −1.3 dB，FIR ≤ −1.2 dB）；
       - 按 L1 最坏情况，轴向满驱动 X3 为 −12.65 dB，FIR 为 −6.76 dB（均相对 D20）。
       - 所以本结构需要一个**联动限幅器**（8 路用同一个增益），或者固定退让：干净方波约 4–8 dB，要保证任何输入（|x| ≤ 1，最坏情况是两电平信号）都不削顶约 10.5 dB，FIR 的对应值约 5.0 dB。退让会直接降低最大声压级（"多响"），叠加在 −2.16 / −3.33 dB 之上；"多响"的需求与余量要等线③（热功率 + Xmax）和 R3 的 L1，目前不能判定；灵敏度（每瓦）不受数字退让影响。见 §2.4。
     - JY/T 8 点单频点全部一级，最薄是 500/30°，余量 +0.22 dB；1 kHz 波束宽 36.1°（FIR V1 为 32.4°，D20 为 29.3°）；正弦满幅归一下轴向 −2.16 dB（FIR V1 为 −1.77 dB）。
     - **只在 1–4 kHz 打平**：5 kHz 观察带的 R90 为 21.1 dB（FIR 35.9，D20 22.9），500 Hz 波束宽 64.3°（FIR 61.4°，D20 60.7°）。把 5 kHz 也放进设计目标可修好 5 kHz（37.1 dB），但 1–4 kHz 良率会降（装好直接用 21.3 → 15.4%），见 §2.3。
     - **驱动前提不成立**：正弦稳态下，c2、c3（阵元 {2,13}、{3,12}）在 1.6 kHz 以上比现表同一路高 +1.17 / +0.55 dB；在瞬态下更高，见上。
   - **算力**：
     - MAC [L3]：69 MAC/样点，即 4416 MAC/帧；FIR-128 × 8 为 32768（对称折叠）/ 65536（直接型）MAC/帧。本结构约为前者的 1/7、后者的 1/15。
     - 核上周期 [L4 包络]：本结构约占帧预算的 0.10–0.17，FIR-128 为 0.74–2.46。
2. **Duran DDC 原样照搬不合适**：DDC 的目标是恒定波束宽（有效长度 ∝ λ）。在我们的阵上，到 4 kHz 有效口径只剩约 2 对喇叭，R90 掉到 8.5 dB [L2]。值得借用的是它"用低阶 IIR 做分频加权、比 FIR 省算力"这个实现手段，而不是它的设计目标。
3. **Keele 的直阵延时 CBT 不适合做 ±90° 抑制，这是本项目自己的 [L2] 结论**：
   - 在我们的阵上，加延时比不加更差：20° 弧时 R90 从 35.8 降到 33.3 dB，装好直接用的良率从 9.0% 降到 2.6%；弧越宽越差；整数样点延时还会更差。
   - 原文只在趋势上与之一致（弧越宽，60° 以外越宽）。原文"±90° 只有约 10 dB"说的是宽弧；窄弧（10–30°）时，原文 Fig. 10 的延时 CBT 在 4 kHz 的 ±90° 仍在 −47 至 −51 dB，只比真曲面差 2–4 dB，而且基准与本文不同。所以不能说"原文已证明它不适合"。
4. **建议（PM 拟，待 CTO 过目）**：X3-LR4 与每通道 FIR 并列为"改架构"路线（DEC-S7-SIDE30-01 ③）的两个候选。
   - **X3 的前提是固件里加一个联动限幅器**（8 路同一增益）。这是一个新的功能件：算力冻结令例外清单里的逐通道保护限幅器不适用于 X3（理由见 §2.4），要不要做由 CTO 定。
   - **若 CTO 不接受联动限幅器，FIR 更合适**：它是线性相位，瞬态余量好，还能做逐通道相位校准。
   - 取舍见 §5。

## 2. 低阶 IIR：共享同相分频 + 每通道频段增益

### 2.1 为什么不照搬 DDC 的"每通道一个 IIR"

- **输入是单声道**，8 路吃的是同一个信号。所以频率相关的加权可以这样做：先把输入分成 K 段（只算一次），再按 8×K 矩阵混合。这样不必每一路各跑一个滤波器。
- **LR 分频器的性质**：各输出同相，幅度之和恒为 1。因此每一路的等效权重 W_c(f) = Σ_k w_k[c]·m_k(f) 是实数，只差一个所有通道共用的全通相位；轴向**幅度**平坦，**相位**是这个公共全通。不需要 DDC 那样的逐通道群延时补偿。
  - 3 段时，高段要多过一个与低分频点相同的全通滤波器，保证三段同相。
  - 这两条性质用**真实的双二阶节**检查过（scipy butter / sosfreqz，1 Hz–20 kHz）：段间相位差 ≤ 1.6e-11 rad，三段幅度之和与 1 相差 ≤ 5e-13，闭式幅度与双二阶节幅度相差 ≤ 5e-13。critic R3f 用 scipy 复核了同相与幅度和（并用 4 种人为注入的错误证明这项检查会 FAIL）；MATLAB 另外复核了"三段之和 = 全通"、全通的 L1、各路 L1 / 正弦比、方波冲高与驱动前提。
  - 公共全通对波束图没有影响，但对波形有影响，瞬态余量因此变差，见 §2.4。
- **与冻结子带树的区别**：树的细节带是没有延时对齐的梳状残差，不能分带加权（DEC-S7-RETRACT-SUBBAND-01）。LR 同相分频器可以分带加权。

### 2.2 设计

- **低段（< 700 Hz）固定为冻结 D20**，保住今天的 500 Hz 表现。
  - 若让低段自由优化，并加"500 Hz 窄波束"目标，就会走向超指向：大权重、含负权，正弦满幅归一下轴向掉 13.8–14.9 dB（日志"EXPLORATORY free-low"一节）。所以低段固定。
  - critic R3f 用另一种设置（低段自由、不加 500 Hz 目标）得到 −8.76 dB，同样是大幅下降。
- **中、高两段**：在 7 个考核频段上，最小化"60–90° 扇区的期望功率 + η × 中间扇区功率"，约束为每段 Σ2w = 1。
  - 分频混合按真实的 m_k(f) 精确计入，用 KKT 方程求解；脚本检查了约束成立和局部最优。critic R3f 确认求解正确。
  - 这与稳健扇区表、FIR 原型是同一个稳健准则（Van Trees 2002 式 2.208）。
- **候选规则**：这条规则是 PM 看过理想值扫描之后定的，不是事先定的。
  - 扫描网格：LR4 / LR8 × 7 种分频点 × 3 种目标（η, 中间扇区）。
  - 入选条件：频段增益全部非负，且 8 个 JY/T 点单频点全部一级。共 18 个候选。
  - 每族取 U-flat 装好直接用良率最高者作代表。这是在带噪估计里取最大，日志里列出了每族全部候选的良率；critic R3f 换新种子复算，没有"赢家诅咒"。
  - 注：本脚本初稿"最差等级"写成了 min，把个别不全是一级的点也放了进来；PM 自查发现后已改正并重跑，本文数字为改正后结果。

### 2.4 瞬态余量、驱动前提、算力、延迟与实现风险

**瞬态余量与驱动前提** [L2 时域仿真；X3 用真实双二阶节，FIR 用真实抽头；日志"HEADROOM / DRIVE PREMISE"一节]：
- **比法**：两者都按"正弦满驱动"归一，即所有通道、所有频率上的最大增益 = 1。输入为满幅信号（峰值 1），看每一路输出的峰值比现表同一路（纯增益，峰值 = 该路 D20 权重）高多少 dB。

| 输入 | X3-LR4，c0..c7 中最大 | FIR V1-128，c0..c7 中最大 |
|---|---|---|
| 100 Hz 方波（含起始段） | +4.12（c2） | +0.00 |
| 1 kHz 方波（含起始段） | **+7.38**（c2）；按绝对电平，c6 超过数字满幅 +5.01 dB（约 1.78 倍），c7 超过 +4.82 dB | +0.44 |
| 3 kHz 方波（含起始段） | +6.63（c2） | +0.03 |
| 粉红噪声（`V_FF_MAX` 的测量信号） | −1.29 | −1.17 |
| L1 最坏情况 | +12.62 | +6.23 |

- **正弦稳态**：c2、c3 在 1.6 kHz 以上比现表同一路高 +1.17 / +0.55 dB；整体退 1.17 dB 就能守住"不比现表更重"，此时轴向从 −2.16 dB 变为 −3.33 dB。
- **方波类瞬态**：退 1.17 dB 不够。按绝对电平，c6 已超过数字满幅 +5.01 dB（约 1.78 倍），c7 超过 +4.82 dB（约 1.74 倍）。
  - 原因是公共全通把不同频率成分错开了（群延时 0.92 → 0.07 ms），方波的各谐波不再同时到达峰值。FIR 是线性相位，没有这个问题。
  - critic R3f 得到的 +7.8 dB（3 kHz）来自 sign(sin) 生成的两电平信号，边沿有一个样点的抖动，也是合法信号；critic 用本文的干净方波逐位复现了方波（含起始段与稳态）、L1（各路与轴向）、群延时与驱动前提各数；粉红噪声的数值取决于噪声样本（critic 的样本得 X3 −0.48 / FIR −0.78 dB），结论相同。
  - 两电平信号的最坏情况会达到 L1 上界：按绝对电平，c6 超过数字满幅 +10.48 dB，c7 超过 +10.36 dB。所以"4–8 dB"只覆盖干净方波，**保证任何输入（|x| ≤ 1）都不削顶须退约 10.5 dB**；FIR V1-128 的对应值约 5.0 dB（c0）。
- **固件阶段的余量方案须三选一，待 CTO 定**：
  - ① **联动限幅器**（推荐）：8 路各自检测峰值，但用同一个增益同时压 8 路，保持加权比例；或者在输入端放一个带预读的限幅器，但它的检测必须看分频后各路在预读窗口内的输出——只看输入电平挡不住各路约 +5 dB 的冲高。
    - 注意：算力冻结令例外清单里的是 DEC-S5-EQ-O1-01 的逐通道保护限幅器（阈值 T_k = T·w_k）。它在纯增益表下能保住锥度，是因为那时 8 路是同一波形的缩放，等效于联动。X3 的 8 路滤波各不相同，若各自独立限幅，大信号瞬态时加权比例会变，±90° 抑制随之变差。
    - 所以联动限幅器是一个**新的功能件**，是否纳入例外清单、要不要做，由 CTO 定。
  - ② 固定退让：干净方波约 4–8 dB，保证不削顶约 10.5 dB（FIR 约 5.0 dB）。退让会直接降低最大声压级（"多响"），叠加在 −2.16 / −3.33 dB 之上；"多响"的需求与余量要等线③（热功率 + Xmax）和 R3 的 L1，目前不能判定；灵敏度（每瓦）不受数字退让影响；
  - ③ 换成相位更好的分频：线性相位互补 FIR 分频，或色散更小的 LR2 / 相位均衡。算力会上升，没有评估。
  - 无论选哪种，`V_FF_MAX` 的复核都要按瞬态而不只按正弦来做。

**算力**：

| 结构 | MAC/样点 | MAC/帧（64 样点）[L3] | 核上 cyc/帧 [L4 包络，×30–50] | 占 1.333 M 帧预算 [L4] |
|---|---|---|---|---|
| X2-LR4 | 36 | 2304 | 69–115 k | 0.05–0.09 |
| **X3-LR4** | 69 | 4416 | 132–221 k | **0.10–0.17** |
| X3-LR8 | 114 | 7296 | 219–365 k | 0.16–0.27 |
| FIR-128 × 8（`fir/s7_fir_compute.csv`） | — | 65536 直接 / 32768 折叠 | 0.98–3.28 M | 0.74–2.46 |

- **计数方法**：每个双二阶节按 5 MAC 计；LR4 的一次分频 = 低通 2 节 + 高通 2 节；3 段时高段另加 1 节全通；混合为 8×K MAC。帧预算假设 CCLK = 1 GHz，须用板上读回的 CCLK 重算（DEC-S7-RULINGS-03）。1/7–1/15 是 MAC 之比 [L3]；换算成周期要乘板证因子，而这个因子对递归 IIR 没有板上数据，所以周期一栏只是 [L4] 包络。
- **延迟** [L2]：公共全通的群延时在直流处为 0.92 ms，1 kHz 处 0.72 ms，4 kHz 处 0.07 ms；FIR-128 恒为 63 样点，约 1.31 ms。
- **其他实现风险**：
  - 其一，21569 有 IIR 加速器，本文没算，须 bench 实测。
  - 其二，定点：critic R3f 复核了系数量化（Q2.14 系数下 LR4 的同相性仍精确）和 float32 数据通路（误差约 −111 dB）；朴素 Q2.14 的 LR8 会下溢。**定点数据通路没有评估 [L4]**：舍入噪声（极点半径约 0.937）、内部溢出（全通的 L1 为 4.33，即 +12.7 dB）、极限环。
  - 其三，**假绿陷阱**：三段相加恒等于"全通后的输入"，与各段增益无关，这与 PR telescoping 同类。所以板上验证必须逐通道比对，并且必须有一个会 FAIL 的占位对照（例如三段增益全部等于 D20）。
  - 其四，需要新的 golden、自检锚、宏门控（默认关，默认 build 预处理等同）和板门。

## 3. Duran DDC 原样（恒定波束宽）

- **做法**：按原文式 (3-1)，L_eff = (69°/30°)·λ，有效口径内加升余弦窗。原文没写窗型，窗型是 PM 选的。滤波器按理想（零相位）计，这是 Bessel IIR 实现的上限。数值保护：有效半口径不小于 0.6 个间距，只在约 12 kHz 以上起作用。
- **结果** [L2]：
  - R90 在 1k–3.15k 为 30.4–31.9 dB，**4 kHz 掉到 8.5 dB**：到 4 kHz，有效口径只剩约 2 对喇叭，离散采样撑不住窗形；
  - 1 kHz 波束宽 51°：这是窗型造成的，目标 30° 是按均匀口径的公式算的；
  - 满驱动轴向 −16 dB：高频有效口径不断缩小，却仍保持轴向平坦，即 Keele 所说的"每倍频程功率降 6 dB"；
  - 各策略良率都是 0%。
- **判断**：DDC 追求的是恒定波束宽，我们要的是 1–4 kHz 全段压 ±90°，两个目标冲突。这条判断不取决于窗型。

## 4. Keele 直阵延时 CBT

**做法**：按原文式 (3)–(7)，H_T = N·d（按原文文字"长度加一个间距"）。弧角取 20°、30°、45°、60°，另外评估两种变体作对照：延时取整到 48 kHz 样点；只加 Legendre 加权、不加延时。
- 注：按原文 Fig. 1/2 的加权数值反推，H_T 应为 (N+1)·d；critic R3f 用 (N+1)·d 复算，结论不变。

**结果** [L2]：

| 设计 | R90，7 频段最差 | 1k/30° | 轴向 | 装好直接用良率（U / G） | 配对 + 微调 |
|---|---|---|---|---|---|
| 只加 Legendre 加权（不加延时） | 35.8 | 17.56 | −2.25 dB | 9.0 / 10.8 | 83.6 / 62.0 |
| 延时 CBT，20° 弧 | 33.3 | 15.61 | −3.7 至 −2.3 dB | 2.6 / 3.2 | 65.5 / 37.1 |
| 同上，延时取整到样点 | 25.0 | 15.12 | −4.1 至 −2.4 dB | 0.0 / 0.0 | 0.1 / 0.0 |
| 延时 CBT，30° 弧 | 30.9 | 13.98 | −5.1 至 −2.5 dB | 0.0 / 0.1 | 22.5 / 5.7 |
| 45° / 60° 弧 | 23.1 / 16.0 | 11.64 / 9.63 | 更差 | 未跑 MC | — |

- **判断**：延时让波前"弯曲"，把能量摊到更宽的角度，正前方的相干和随之下降（轴向高频损失），±90° 反而变差。
  - 这是本项目在自己的阵和目标上得到的 [L2] 结论；原文只在"弧越宽越差"的趋势上与之一致（见 §0 第 3 条）。
- **对称串联结构本身兼容延时 CBT**：每对喇叭的延时和加权相同。所以"不兼容"不是它被否定的原因，否定它的原因是目标不对。
- Legendre 加权本身只是又一张固定表（良率 9.0%，介于 D35 的 6.0% 与 RS-B 的 10.4% 之间），没有必要再加一张。

## 5. 建议与下一步（PM 拟，待 CTO 过目）

1. **路线**：X3-LR4 与每通道 FIR 并列为"改架构"路线（DEC-S7-SIDE30-01 ③）的两个候选。取舍如下：

   | 方面 | X3-LR4（共享同相分频） | FIR V1-128（每通道） |
   |---|---|---|
   | 7 频段良率 | 打平 | 打平 |
   | MAC | 约 1/7–1/15 | 基准 |
   | 瞬态余量 | 差：方波最多 +7.4 dB，要联动限幅器 | 好：≤ +0.4 dB |
   | 5 kHz 观察带 | 21.1 dB，要加第 4 段或改目标 | 35.9 dB |
   | 1 kHz 波束宽 | 36.1° | 32.4° |
   | 逐通道相位校准 | 做不到 | 能做 |

2. **PM 的倾向**：
   - 若 CTO 接受增加一个联动限幅器（新功能件），X3 是首选：算力风险小得多，FIR 的算力至今未证实。
   - 若不接受，或逐只喇叭测量显示相位离散大、随频率明显变化，则选 FIR。
3. **判断点**：
   - 逐只喇叭测量（会话 ⑤ S-DRV）的结果：离散以幅度为主、随频率变化不大，则 X3 + 每路每段实数微调就够；否则上 FIR。
   - CTO 对联动限幅器的态度。
4. **若 CTO 同意继续 X3**，下一步依次为：
   - 桌面补评：加第 4 段修 5 kHz；联动限幅器建模（轴向压缩量、预读延迟、算力、对良率与 ±90° 的影响）；相位改良方案；
   - 主机 C 原型（float32），做逐通道 golden，并准备会 FAIL 的占位对照；
   - 固件包：新宏，默认关，默认 build 预处理等同。**这是一个新的固件包，须单独 CTO_OK**（DEC ④ 的逐包规则）；
   - 做一次 IIR 路径的 bench 周期测量（类似 S-FIRB），用 L1 数据替换本文的 L4 周期包络。
5. **测试员这边不变**：会话 ①–⑥ 的顺序与内容都不受本文影响。

## 6. 模型局限（同 `S7_SIDE30_ANALYSIS.md` §7）

- 各向同性点源，没有障板和箱体衍射，也没有逐只喇叭离轴指向性的离散。±90° 正是沿箱体掠射的方向，是模型最不可信的地方。
- 误差模型（U-flat / G）是假设，所以良率一律标 [L2 on L4 spread]。
- 瞬态余量用的是合成信号（方波、粉红噪声）和 L1 最坏情况；真实节目素材的峰值因数介于两者之间，须结合联动限幅器设计再评。
