## 0. 口径：测什么、"30 dB"指什么、本文取代 §8.1 的哪部分

### 0.1 被测量
**侧抑 R(b, θ) = L(0°, b) − L(θ, b)**（dB），b = 1/3 倍频程带，θ ∈ {+60°, −60°, +90°, −90°}，同一半径、同一会话、同一电平。每带报两侧中**较差**的一侧 R_worse(b, θ) = min(R(b,+θ), R(b,−θ))（对 90° 即口径的 R90 = L(0°) − max[L(±90°)]），同时报两侧差（对称性）。

### 0.2 "20 → 30 dB"
- "20 dB" 起点是否即 DEC-S7-OBS-OWNRIG-01 的 **[L0] 口述观察**（条件 10 项全未记录）待 CTO 确认（`S7_SIDE30_ANALYSIS.md §0`）；它**不是基线、不作判据**。本文基线跑出来的才是第一份 [L1]。
- "30 dB" 口径 = **DEC-S7-SIDE30-01 ①**（PM 拟、CTO 同意正式化，**参数待 CTO 过目**）：**1/3 倍频程 1k–4k 各频段（1000/1250/1600/2000/2500/3150/4000）R90 ≥ 30 dB；远场自由场，r ≥ 8 m，3 次重复取中值，本底比侧面读数低 ≥10 dB。** 本文照此执行；±60° 与 500–800 Hz、5k、6.3k 带是**补充信息**，不在口径内（除非 CTO 另定）。
- **室内不能验证 30 dB**：混响把侧向读数垫高 → 室内读数只会显得更差，既不能证明达标也不能证明不达标。
- 冻结 Dolph-20 表在**无误差各向同性模型**下的 ±90° 带平均值**本身低于 30 dB** [L2 模型，`sprint7/tools/s7_driver_pairing.py` 可复算]。这是模型参考值、**不是物理上界**（喇叭/箱体自身指向性可能使实测更高）→ 现装配基线**不以达标为目的**，但照口径照样判读、如实记录；对 30 dB 的判定主要用于 CTO 选定的候选表（§10）。

### 0.3 本文取代 `S7_VERIFICATION_PLAN.md §8.1` 的部分（仅限侧抑这个指标）

| §8.1 原规定 | 本文 | 理由 |

## 3. 场地、架设、距离、反射

### 3.1 架设
- 室外空旷地；**阵列横放（长轴水平）**，broadside 正前；阵列中心与麦**同高 h ≥1.5 m**；麦三脚架 + 防风棉。
- 转动平面 = 阵列长轴所在的水平面；**阵列不动、麦在恒定半径弧上移动**（主瓣始终朝同一方向，环境反射不随角度变）。0°/±60°/±90° 在地面按半径拉尺标点（±90° 即阵列长轴延长线上）。
- 记实际半径（每个角度实测一次）、高度、阵列朝向（指南针或地标）。

### 3.2 距离

| ±60° / ±90° 侧抑（本文主测，**口径判读**） | **r = 8 m（全带）；口径判读 r ≥ 8 m 为硬条件** | DEC-S7-SIDE30-01 ①；下表 |

### 3.3 反射控制与地面反射触发（要读 30+ dB 的差，这一节决定成败）
1. **主瓣方向留空**：主瓣（0° 方向）前方尽量没有大平面（墙、车、围栏、楼）。[L3] 估算：主瓣正对一面理想镜面反射墙（距离 D），在半径 r 处反射声比正前直达声约低 20·log10(r/(2D)) dB；要它比待测侧向声再低 10 dB，须 20·log10(2D/r) ≥ R目标 + 10。实际墙面不正对、不理想，反射小得多——所以**记录**：主瓣 ±15° 扇区内最近大反射物的类型和距离、背后同样，交 PM 评估；测试员**不自行判"够不够"**。
2. **麦附近 3 m 内无人无物**：测量员站到麦后方远处（遥控/延时开始 Leq），不站在阵列与麦之间，也不站在主瓣里。
3. **地面反射会双向偏 R**（[L3] 几何）：阵列对其长轴轴对称。到 0° 麦位的地面反射走的是阵列的主瓣方向（与直达声同量级）；到 ±90° 麦位的地面反射离长轴约 atan(2h/r)，即相当于 broadside 的 90° − atan(2h/r)（h = 1.5 m、r = 8 m 时约 **69°**，旁瓣区）。两处反射相对各自直达声的强弱不同 → R 可能被读高也可能被读低。草地/土地优于水泥；所有角度同高同半径。
4. **地面反射触发（所有方案）**：每个口径带、每一侧，距离不变性检查（§5 步 9）不过 → 该格标"**地面/反射污染**"，不参与口径判读。
   **"地面反射未隔离"标注：本文所有 R 格（±60° 与 ±90°）在所有方案、所有频带一律带上，门控不能解除。** 物理原因（[L3]）：麦在 ±θ 时，16 只喇叭的直达声按各自到麦的路程先后到达，前后跨度 L·sinθ/c——±90° 时麦在阵列长轴延长线上，跨度 = L/c = 0.825/343 ≈ **2.4 ms**；±60° 时约 **2.1 ms**。地面反射比直达声晚 [√(r²+4h²) − r]/c，h = 1.5 m、r = 8 m 时约 **1.6 ms**，**短于**直达声的跨度 → 直达声与地面反射在时间上交错，任何时间门都分不开。门控只可能在直达声跨度短于地面反射滞后的角度上起作用（本几何下约 ±40° 以内，如 0°），且须证明该带的门确实把反射排除在外；本文的 R 格都含 ±60°/±90° 读数，因此不适用。
   若要让 ±90° 的地面反射可门控，须 √(r²+4h²) − r > L，即 h > √(L² + 2rL)/2（r = 8 m 时 **h > 约 1.9 m**，阵列与麦同高；h = 3 m 时地面反射滞后约 5.8 ms > 2.4 ms）[L3]——是否这样架设见 §15 Q13。
5. 方案 A 的门控交叉核（§5 步 10）只查**非地面**反射（墙、车、人等更晚到的反射）：门必须把全部 16 只的直达声都包进去，因此地面反射也必然在门内；门控与不门控的侧抑差超过重复性散布 → 该点有非地面反射污染，报门控值并注明（仍带"地面反射未隔离"）。

## 4. 信号、电平、SNR、动态范围

### 4.1 信号
- **逐带 1/3 倍频程粉噪**，中心 500, 630, 800, 1000, 1250, 1600, 2000, 2500, 3150, 4000, 5000 Hz + 6300 Hz（栅瓣检查）。所有文件**同一数字 RMS**，每个文件时长 ≥ Leq 时长 + 5 s；另为 §4.3 生成每带 −10/−20/−30/−40 dB 数字衰减版本。文件由 dsp/PM 预生成并交付清单、md5 与**每个文件的带外衰减实测谱**，测试员不自行生成。
- **带外衰减要求**（防止带外泄漏在侧向位置把读数垫高，方案 C 尤其）：[L3] 若带外能量比带内低 A_oob，侧向读数的泄漏误差 < 0.1 dB 需 A_oob ≥ R_max − R_oob,min + 16 dB（R_max = 想读到的最大侧抑，R_oob,min = 带外频率上阵列最差的侧抑）。**生成规格 [L4 暂定，按上式取 R_max ≈ 40、R_oob,min ≈ 6 dB（≤400 Hz 与栅瓣区，`S7_SIDE30_ANALYSIS.md §2` [L2]）推得，CTO/dsp 可改]：距带边一个倍频程以外 ≥ 50 dB；相邻 1/3 oct 带中心处 ≥ 30 dB（相邻带上阵列侧抑与带内相近，按上式只需约 16 dB，30 dB 是留的余量）。** 方案 A/B 的 RTA 自带带通滤波，对相邻带有额外衰减。
- **warble（±5%）不作口径判读**：它只覆盖 1/3 oct 带宽的一部分，读数与带平均系统性不同——对 Dolph-35 [L2 模型，本文作者复算，与 critic R3c 一致]：1.25k/1.6k/2k 带高读约 +1.5/+2.5/+1.4 dB，1k/2.5k 带低读约 −1.1/−1.9 dB。用 warble 测的格子一律标"**不可判（口径外）**"，除非 CTO 明确认可（§15 Q4）。
- 信号从板的音频输入进（M2 波束在环），不直接驱动功放。

### 4.2 电平、线性与驱动上限
- **驱动上限 `V_FF_MAX = ____ Vrms`（CTO 定，§15 Q3；厂家热额定/Xmax 回函前必填）**，**在驱动中心对 {7,8} 的那一路功放输出端测**（权重 c7 = 1.0，是全表最大的一路；是哪一路功放通道按极性 QA Phase A 的通道→位置映射确定）；万用表 AC 档，1 kHz 带粉噪或正弦；同时记对应的功放档位 ____。其它路按权重更低（冻结 Dolph-20 最低约 −6 dB，候选表更低），所以 c7 这一路决定上限。任何时候不超过；换权重表（§10）后先确认 c7 仍是最大权重路。
- 按 `S7_VERIFICATION_PLAN.md §8.1` 步 5：功放从最小起调到 0° 读数充分高于本底且 `g_m1_max_abs_sample` 不近满幅，**且 ≤ `V_FF_MAX`**；记功放档位。
- **线性检查**：若当前档位**再抬一档仍 ≤ `V_FF_MAX`**，抬一档测 0° 与 +90° 各一遍；若当前已在上限，改为**降一档**测同样两点。两档下的侧抑之差在重复性散布内才继续（否则在限幅/压缩区，退回）。全程电平不变。

### 4.3 动态范围自检（读 30+ dB 的必要条件）
在 0° 位置、每带：依次放 0、−10、−20、−30、−40 dB 数字衰减文件，各读 Leq。读数应随衰减同步下降（差值在该点重复性散布 + 仪器分辨率内）。**保持同步的最深一档 = 本会话该带可读深度 D_max(b)**。任何侧抑读数若超过 D_max(b)，只能报"**≥ D_max(b)**"。（手机 App 的底噪、自动增益、计权都会在这一步暴露。）

### 4.4 本底与 SNR
- **本底的测法**：整条链**保持通电**（板在跑、功放上电、音量档不动），**只把信号源静音**（播放器停/静音文件），每个麦位、每带 Leq 同时长，3 遍（方案 C 读宽带本底，同计权）。这样功放/DAC 自噪声算进本底。
- 两道门并存（CTO 可统一，§15 Q5）：**口径门**（DEC-S7-SIDE30-01 ①）= 本底比该读数低 ≥10 dB，过了才可参与口径判读；**报数门**（skill A3）= ≥15 dB 才作为无标注数值报，10–15 dB 之间照报但标"SNR 10–15"。**<10 dB**：本底只会把侧向读数垫高 → 真实侧抑 ≥ 读出值 → 该点报"**≥ R（本底限）**"，不作为数值，不减本底修正。
- 规划要求（非读数期望）：要读出 R dB 的侧抑，正前该带须高出本底约 R + 15 dB（例：想读 35 dB → 正前约 50 dB 以上 SNR）。**这个 SNR 必须在 `V_FF_MAX` 之内得到**；得不到 → 该带只报下限"≥ …（上限电平下本底限）"，**不得为了 SNR 超上限**，改为换更安静的时段/场地（§13）。

## 5. 测量流程

1. **build/gate/安全**：按 §8.1 步 1–2 + §0.5（功放断电读表 → 上电 → 最小音量）。抄 build 指纹进 R10 第 7 项。
2. **架设**（§3）；记半径/高度/朝向/反射物（§3.3-1）。
3. **本底**：在 0° 麦位，链路通电、信号源静音，逐带 3 遍（§4.4）。
4. **电平与线性**（§4.2，≤ `V_FF_MAX`）。
5. **动态范围自检**（§4.3），得每带 D_max(b)。
6. **测量矩阵**（r = 8 m）：麦位顺序 0° → +60° → +90° → −60° → −90° → **0°（复测）**。每个麦位：本底逐带 1 遍（首个麦位已做 3 遍）→ 逐带信号各 Leq 10–30 s（全会话同一时长）→ 整组重复共 **3 遍**（麦不动，重新起 Leq）。抄原值。
7. **0° 首末比较**：首末 0° 读数之差超过其散布 → 记"漂移"（风/温度/电平），该会话数据标注，交 PM。
8. **对称性**：±θ 两侧差异很大时，先查阵列朝向与弧半径，再重测该角。
9. **距离不变性检查（口径 7 带 × 两侧，§15 Q6 可调）**：把麦移到第二半径（16 m 优先；或 4 m），测 0°、+90°、−90°，口径 7 带（1000…4000）各 3 遍。同带同侧侧抑之差 > u_1 + u_2（第二半径用 4 m 时再加 §3.2 该带近场偏差的绝对值）→ 该格"**地面/反射/本底污染**"，不参与口径判读（§3.3-4）。
10. （方案 A）**门控交叉核（只查非地面反射）**：在 0° 与 ±90° 各做一次扫频冲激响应。门以 0° 测得的直达声到达时刻 t0（对应阵列中心到麦的距离）为中心，在 ±90° 至少覆盖 t0 ± L/(2c) ≈ t0 ± 1.2 ms（全部 16 只的直达声），结束在首个**非地面**反射之前（**不要**在 ±90° 自动找峰——那里直达声可能比反射还弱）；按 1/3 倍频程算门控侧抑，与 Leq 结果对照。地面反射必然在门内（§3.3-4）。
11. **垂直复核**（§8.1 步 11）：0° 上下各偏一个小角，确认 0° 在垂直方向也最大。
12. 填 R10（§8）、表格（§7）；原值、截图、照片一并发回。

时长参考：12 带 × 6 麦位 × 3 遍 × Leq 时长 + 第二半径 3 麦位 × 7 带 × 3 遍，外加本底与自检；按 20 s Leq 约 2–2.5 小时，挑无风时段（清早）一次做完。

## 6. 计算（PM 侧；测试员只交原值）

对每带 b、每角 θ：
1. L0 = 0° 首次 3 遍的中值（首末漂移未超散布时用首末 6 遍中值）；Lθ = 该角 3 遍中值。
2. R = L0 − Lθ；R_worse = min(R(+θ), R(−θ))；对称差 = |R(+θ) − R(−θ)|。
3. 不确定度（[L4] 工作假设，CTO 可改）：u_x = max(3 遍极差/2, 仪器分辨率)；u_R = √(u_0² + u_θ²)。
4. **有效性标记**（任一触发 → 该格报下限"≥ …"或"不可判"，不报数值，不参与口径判读）：
   - 本底限（§4.4，<10 dB）；上限电平下本底限（§4.4）；
   - 超 D_max（§4.3）；
   - 距离不变性不过 / 地面反射污染（§3.3-4、§5 步 9）；
   - 漂移（§5 步 7）；门控不一致（§5 步 10）；
   - **warble 格子**（§4.1）：不可判（口径外），除非 CTO 认可；
   - r < 8 m 的格子：只作探索。
   所有方案的 R 格（±60°/±90°）一律另标"地面反射未隔离"（§3.3-4；门控不能解除；不单独使之无效，但结论必须带这句，地面反射可能把 R 读高也可能读低）。
5. 对口径（DEC-S7-SIDE30-01 ①，T = 30 dB，1k–4k 每带）的判读：**按口径用中值：R90 = L0 − max(L+90, L−90) ≥ T → 该带达标**；本文另报不确定度，**R90 − u_R < T ≤ R90 的带标"临界"**、R90 < T ≤ R90 + u_R 的带标"临界未达"，供 CTO 参考（是否以不确定度收紧口径 = §15 Q7）。下限类格子只能判"达标（下限已过）"或"不可判"。
6. 栅瓣检查（6.3 kHz）：[L3] 几何上 f = c/d ≈ 6.2 kHz 时栅瓣峰到达 ±90°；栅瓣与主瓣同宽，其裙边在更低频就进入 90°（Dolph-35 约 5.7 kHz 起，critic R1 F11）→ 5 kHz 带上沿可能已受影响，6.3 kHz 带 ±90° 侧抑应**明显小于** 4 kHz 带（"明显" = 差值大于两者 u_R 之和）。未见 → 查角度/距离/反射/通道映射，不改结论口径。这是对阵列几何的定性自检，不是规格。
7. 结果口径：R 只作"本装配、本 build、本场地"的 [L1 自由场现场] 值；与工具预测（[L2]）并列时必须分栏，不得混写；现装配基线与 `s7_driver_pairing.py --as-built` 预测的对照只作模型检验，不互相替代。

## 9. 能声称 / 不能声称

**能**（均为 [L1 自由场现场，1/3 oct，本装配/本 build/本场地]）：
- 各带 ±60°/±90° 侧抑 R 及其不确定度；在有效性门都过、r ≥ 8 m 的格子上，按 DEC-S7-SIDE30-01 ① 口径的逐带判读（含"临界"标注）——**全部带"地面反射未隔离"**（§3.3-4），除非按 §15 Q13 抬高架设并用方案 A 门控核实。
- 同会话、只换权重表（其它一切不动）的 **A/B 相对差**（§10）。
- 6.3 kHz 栅瓣的定性出现（几何自检）。
- 现装配基线作为 `s7_driver_pairing.py --as-built` 模型预测的对照（模型检验，不是替代）。

**不能**：
- 任何超过 D_max、本底限、上限电平下本底限、距离不变性/地面反射不过的格子的数值（只有下限或不可判）。
- warble 格子的口径判读（除非 CTO 认可）。
- 30°/波束宽（本文不测；需 2L²/λ）；绝对 SPL；室内/现场使用环境下的侧抑。
- 对外规格（仍待 R3 消声室；手机/现场半定量链只支撑本文口径）。
- "侧抑提升来自配对/来自换表"之类的归因——归因需要 `S7_DRIVER_MATCHING_RUNBOOK.md` 数据 + 模型，且只到 [L2]。
- 单会话"30 dB 已达成"作为 LOCKED 依据——是否需要跨日复测由 CTO 定（§15 Q8；可逆性不得自我降档）。
- 把 L0 观察值（DEC-S7-OBS-OWNRIG-01）拿来和本文数值比较作判据。

## 13. 失败处理

| 现象 | 处理 | 禁止 |
|---|---|---|
| 动态范围自检在浅档就不跟 | 换方案 A 或更好的 App；本会话只报下限 | 不拿超 D_max 的读数报数 |
| 本底太高 / 在 `V_FF_MAX` 内 SNR 不够 | 换更安静时段/场地；该带报下限 | **不超上限加电平**；不做本底减法"救"数据 |
| 距离不变性不过 | 查反射物/本底；换场地或加门控核；该格不参与判读 | 不挑"好的那个半径"交 |
| 首末 0° 漂移 | 查风/温度/电平；重测 | 不只报一半 |
| 拓扑停止门触发 | 停，原样发回 | 不测 |
| 板 gate 不符 / 读数怪 | 原样发回，停手 | 不重烧、不改宏、不 reset git |
| 异响/发热/异味 | 立即功放断电，记录，发回 | 不继续 |
