> **一句话**:同场地把**竞品整机**、**我们整机(B/修对)**、外加**单喇叭对照**背靠背测方向图,**扣掉单喇叭本身方向图后**比较两者的**纯阵因子 −6dB 波束宽随频率**曲线,判断竞品的指向优势(若有)到底来自:①**恒定波束宽处理**(覆盖均匀,可用 subband 匹配)②**更大孔径/不同几何**(非算法)③**更指向的喇叭单元**(非算法)④**偏转/多模式**(16 通道硬件)。
>
> **⚠ 先摆正一个物理事实(否则会误判)**:在 825mm 这个锁定孔径上,**低频指向被孔径封死**,算法(含 subband/超指向)撬不动(1k 距超指向天花板仅 1.9dB 且需 WNG=−43dB 不可实现)[L3]。**所以本测不是去问"竞品低频是不是更窄的原始指向"(那不可能),而是分辨它的优势是上面哪一类。** 尤其:**"恒定波束宽"≠"低频更指向"**——它靠**放宽高频**去对齐低频宽度,买的是覆盖均匀+离轴音色不变,不是低频变窄。
>
> **为什么可信**:同场地、同信号、背靠背 → 环境(地反/风)对各台**共模等同** → **相对差是真的**。但注意:共模只抵消环境,**不抵消喇叭方向图/近场/EQ/噪声底**(见 §0、§6),故必须做单喇叭对照 + 各项门。

## 0. 能回答/不能回答什么(读之前必看)
**能**(相对、抗环境):扣掉单喇叭方向图后,竞品 vs 我们的**纯阵因子**谁的波束宽随频率更**恒定**、谁在中高频更**窄**;竞品有没有**偏转**;竞品栅瓣频率是否与我们相同(反推 d 是否相同)。
**不能**:各自的绝对波束宽规格(要按频点远场 + 消声室/门控);也**不能**指望本测证明"竞品低频指向更强"——**物理上不可能**(见上)。
**共模能抵消的**:地反、风、场地(甲乙丙同设置)。**共模抵消不了、必须单独处理的**:①喇叭单元方向图 E(θ,f)(用 §1b 对照扣除)②近场锥形失真(§2 按频点远场)③离轴 EQ 差/限幅(§4 电平不变性门 + §6 峰值归一)④噪声底填零点(§4 逐点 SNR 门)。

## 1. 被测对象
- **甲 = 竞品整机**:竞品 DSP+功放+竞品喇叭,默认模式;机身有**模式/覆盖/偏转开关 → 逐一记并各测(§5.5),这本身验证"有没有多套算法"**。
- **乙 = 我们**:我们板+我们功放+竞品喇叭,烧 `-DM2_CHMAP_FIX`(默认 B,已推 origin `99143fd`)。

### 1b. 丙 = 单喇叭对照(critic B1,决定成败的一步)⭐
**我们板只驱动 8 路里的 1 路 → 只响 1 只竞品喇叭**(用 §诊断 solo 掩码,如 `g_stxt_ch_mask` 或直接只喂 1 通道),**同一转轴、同一麦位**,做完整极图扫。这测的是**单只竞品喇叭自己的方向图 E(θ,f)**(甲乙共用同型喇叭 → E 可共享)。
- 用途:§6 把甲、乙的极图**在 dB 域各减去 E(θ,f)**,得到**纯阵因子** AF_甲、AF_乙,再比——否则"高频变窄"分不清是算法还是喇叭。
- 附带:验证"甲乙喇叭同型/一致"假设;E 若在高频已很指向,直接量化"喇叭贡献了多少窄"。

## 2. 距离(按频点定远场;不要再用单一 8m 糊高频)
r_ff=2L²/λ,L=0.825m → **1k≥4m、2k≥8m、4k≥16m**。
- **1k、2k**:8m 都满足(1k 是 2× 远场,富余;修正旧稿"8m@1k 在边界"的错误说法)。
- **4k**:8m 只有半个远场距离=**菲涅尔近场**,主瓣会因 taper 展宽、而 taper 正是甲乙的未知差异 → **近场失真不共模、不能在 8m 读 4k 波束宽**。→ **4k 必须 ≥16m**;没场地则做**距离不变性检查**(同一台在 8m 与 ~16m 各测 4k,若波束宽随距离缩小=还在近场,数据作废)。
- **省法**:1k/2k 在 8m 一起测;4k 单独拉到 16m(或做不变性检查)。丙对照在**每个用到的距离**都要测(E 也随距离/频率变)。

## 3. 装置
- 空旷地,**同一块、同日**;音柱**横放、broadside 正前、阵列轴水平**;置**转台/标角转轴上,转轴穿阵列声学中心**(转动到麦距离恒定)。
- 麦:正前、与阵列**同高**、按 §2 距离。
- 音柱+麦**抬高离地 ≥1.5m**(压地反;共模,但抬高绝对数更干净)。
- **确认转动平面 = 阵列指向平面**(横放后转台绕竖轴转的是阵列轴所在的水平面;别测成了另一平面)。

## 4. 信号 / 频点 / 测角 / 门
- **信号(统一一种,甲乙丙都用)**:**warble ±5%**(窄带,~±5% 带宽),读 Leq。**别混用 1/3 倍频程粉噪(带宽~±12%,高频抹糊会偏)。** 要更干净可用 FFT 1/12 oct 定点。
- **频点**:**1k / 2k / 4k**(决定性)+ 750 / 1.5k / 3k(补趋势)+ **6–8k(几何交叉核)**:我们 d=55mm 栅瓣在 6.2–8k;若竞品栅瓣**同频出现 ⇒ d 相同**(证"几何=我们"),不同 ⇒ 几何不同。
- **测角**:**0–30° 用 5° 步**(2k/4k 的 −6dB 交点落在 0–15°,15° 步会靠插值造假),45/60/90 粗测。先左右都测确认对称。
- **逐点 SNR 门(critic M4)**:**每个 角度×频率×台**都要 signal−noise ≥15dB 并记录。竞品若高频 EQ 滚降,其 4k 离轴会沉到噪声底→零点被填→**假"恒定波束宽"**;归一化不救。失门的点抬电平或剔除,**绝不让噪声底把曲线撑宽**。
- **电平不变性门(critic M5)**:**别喂"相同电平"**(甲是整机有自带增益/限幅,乙是我们板,同电平无意义且可能把某台推入限幅→改 taper→改波束)。改为:**每台各自工作在线性区 + SNR 够**,并**每台在两个驱动电平各测一次,归一化方向图必须不随电平变**(变=在限幅/压缩,退回线性区重测)。

## 5. 流程
1. 记本底、距离、高度、各台电平、温湿度、风况。
2. **丙(单喇叭对照)**先测:每个用到的距离,solo 1 路 → 0→±90(0–30° 5°步)Leq 3次中值 → 得 E(θ,f)。
3. **甲(竞品)**:各频点 0→±90 同法;做电平不变性抽检。
4. **乙(我们B)**:**同转轴、同麦位、同信号**,整套重复;电平不变性抽检。
5. **(竞品有模式开关)** 每模式把 1k/2k/4k 各测一遍;不同模式波束宽/主响方向明显变 = **实锤多套算法/偏转**。

## 6. 分析 + 判定(2 维读,别用 1 维)
**处理链**:①每台极图**先找真峰值角**(密采样;若峰不在 0°→可能偏转,记峰角,见判定④),**归一化到峰值**(不是默认 0°,critic m1)。②**dB 域减去 E(θ,f)** 得纯阵因子。③读纯阵因子 −6dB 波束宽。④**给误差棒**:1.5dB 重复性 [L1] 落在 −6dB 陡坡上≈**±2–3° 波束宽不确定度**;**甲/乙 波束宽差必须 > 此不确定度**才算数(critic M3)。⑤**物理下限核**:1k 同孔径 −6dB 全宽有 ~28–30° 硬下限;竞品若测出**低于下限 ⇒ 更大孔径或伪值**(critic m3)。

**判定矩阵(两轴:纯阵因子在中高频谁更窄 × 波束宽随频率平不平)**:

| 观察(纯阵因子,已扣 E、已过误差棒) | 结论 | 下一步 |
|---|---|---|
| 竞品**波束宽随频率更平**(高频没我们窄、低频差不多) | 竞品做**恒定波束宽**=**买覆盖均匀/离轴音色不变**,**非低频更指向** | 若产品**要均匀覆盖**→ subband **值得做(交付的是均匀性,不是低频变窄)**;不要均匀就别做 |
| 竞品**中高频明显比我们窄** | 真有更强中高频处理(注:同孔径我们 2k 已距天花板 0.7dB,空间很小,须确认不是残留 E 或近场) | 复核 E 扣除/远场;确认后才谈抄它的中高频法 |
| 竞品**各频段都更窄且低频低于物理下限** | **孔径/几何不同**(非算法);结合 6–8k 栅瓣频率核 d | **回查拆机几何**,不是算法能追 |
| 竞品**峰值不在 0°**,或换模式波束转向 | **偏转/多波束** | **16 通道硬件差距**,单独立项;先按 m7 排除装置不对称 |
| 竞品与我们**曲线基本重合**(扣 E、过误差棒后) | 没有可归因于算法的差距 | 差距在别处或本不显著,别折腾算法 |

> **关键澄清(critic B2)**:①"两条都低频胖"**不能**推出"竞品没做频率处理"——恒定波束宽的竞品**也**是低频胖(它把宽度锁在孔径允许的宽值上)→ 只能靠"高频平不平"区分。②"竞品全频更窄"在"几何=我们"前提下**首先指向几何假设为假或超指向算法**,**不能**直接判"非算法"。③**subband 交付的是"波束宽跨频率恒定=覆盖均匀",绝不是"低频变窄"**(低频被 WNG=−43dB 天花板锁死)——立项文案别写成"用 subband 把低频做窄"。

> ⚠【补标 2026-10-02】上表第一行"subband 值得做"与本段"恒定波束宽"的实现前提已撤回，见文首勘误。

## 7. 防坑纪律
- **必扣单喇叭 E(θ,f) 再比**;**归一化到真峰值**(非默认 0°);**差要大于误差棒**才下结论。
- **4k 不在 8m 读**;逐点 SNR、电平不变性都要过并记录。
- 甲乙丙**背靠背、同场地同日同麦位**;转轴穿阵列声学中心;每角 3 次中值。
- 竞品整机一概别动;我们乙台保持已修极性+B 映射。
- **别把绝对近全向当"阵列/竞品无能"**:结论只下在**扣 E、过门后的相对纯阵因子曲线**上。
- 宣布"偏转"前先排除装置不对称(0°没校准/麦偏置/风/地面不对称)——要求离轴峰在多频点、左右扫里**可复现**(critic m7)。
